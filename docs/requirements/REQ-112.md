## 目的
<!-- 【必須】 -->

local ツール package（src/common/tools/<name>/local/）とルート package（src/common/tools/<name>/）の tsconfig 二重管理の統合方針、および local package の typecheck を品質ゲートへ組み込む是非とタイミングを決定として記録し、後続実装要求の判断根拠を提供する。

## 要件
<!-- 【必須】 -->

| 要件ID | 要件 | 受け入れ条件 | 検証 |
|---|---|---|---|
| REQ-112-001 | local ツール package とルート package の tsconfig 二重管理を統合し、Local 側はルート側へ extends で参照して差分を Local 固有設定へ限定すること（二重管理しない） | 同一内容の tsconfig.json が並列に存在しないこと | 実ファイル突合 |
| REQ-112-002 | local package の typecheck を本体リポジトリの品質検査経路へ組み込むこと。組込みタイミングは Local package 内の誤 import 修正完了後とする | 品質検査経路に local package typecheck が含まれ、検査が緑になること | 品質検査経路の実行 |
| REQ-112-003 | gate 組込みの実装自体と tsconfig 構造の実際の変更は本方針決定の対象外であること（方針決定後に別要求として発生） | 方針決定の記録が対象外を明記すること | 要件doc確認 |

## 適用範囲
<!-- 【必須】 -->

- **対象**: src/common/tools/agentdev-gh/（ルート package と local package）のビルド・検査契約。方針の横展開（他 local ツール package への適用）は後続実装要求の判断材料として記録する
- **対象外**: gate 組込みの実装自体、tsconfig 構造の実際の変更、配布・同期契約（REQ-009-016）の変更
