## 目的

ADF の bounded semantic decision 候補として typesafe/Jev が成立するかを検証する第1実験（J2: learning-promote 8軸評価の shadow 評価）の実行資材を、正規 workflow に影響させない standalone 構成で repo 内 experiments/jev-j2/ に整備する。
本要件は実験の一時資材の契約であり、Jev の恒久採用・恒久 Tool（agentdev_semantic）の実装・既存 learning pipeline（REQ-038）の変更を含まない。本実験は正規 workflow を変更しない shadow 評価であり、REQ-048（実行観測と統制縮小評価）の変更評価実験（REQ-048-012 のトリガー）に該当しない。
baseline は過去 ADF 判断の記録（historical baseline / pseudo-label）であり、主指標は agreement（一致率）であって真値測定ではない。実験結果の恒久構造への反映、および実験合否確定後の本要件の retire と experiments/jev-j2/ の処分は別要件で扱う。
