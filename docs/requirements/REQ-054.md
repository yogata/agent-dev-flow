## 目的

変更対象の artifact 種別だけでなく、変更によって変化する依存・実行・環境境界を分析し、change-induced risk を導出する一般能力を ADF の品質プロセスに導入する。導出した case-specific risk を test strategy の入力として投影し、QG-4（最終受入）で初めてリスクを発見する状態を解消する。

本 REQ は req-define の要件展開工程に先立つ分析能力であり、REQ-017-010 の変更影響候補（artifact 差分）の反映とは分析対象が異なる。REQ-017-009/010 は case-open が事前判定可能な追加検証条件を test strategy へ展開し、変更影響候補を execution contract へ反映する工程である。REQ-019 はリファクタリング PR 限定の機械的 gate である。本 REQ はこの両者と異なり、artifact 差分ではなく 5観点境界（dependency / client-server / execution / build-runtime / environment-propagation）を分析対象とする一般能力であり、機械的 gate ではなく分析能力として位置づく。

## 要件

| ID | 要件 |
|---|---|
| REQ-054-001 | 変更誘発境界リスク分析は、dependency boundary、client/server boundary、execution boundary、build/runtime boundary、environment propagation boundary の 5観点境界について、変更差分から change-induced risk を導出すること |
| REQ-054-002 | 変更誘発境界リスク分析は、リスク導出規則（project-local の判断知識）を参照すること。知識の参照は REQ-002-031 が正規所有する extension 読込経路に従い、知識が不在の場合は ADF core の一般規則のみで 5観点境界分析を実行すること（分析を省略しない） |
| REQ-054-003 | 導出した case-specific risk を検証契約へ投影すること。change → risk → verification obligation → test strategy の変換経路を明示契約とし、投影先は test strategy、投影完全性の検査は QG-1（リスク→test strategy 投影完全性）が担う |

## 適用範囲

- **対象**: case-open の execution contract 工程に先立つ変更誘発境界リスク分析能力、5観点境界からの change-induced risk 導出、リスク導出規則の参照契約と不在時挙動、case-specific risk の test strategy への投影契約
- **対象外**: case-open が事前判定可能な追加検証条件の test strategy 展開と変更影響候補の execution contract 反映（REQ-017-009/010）、リファクタリング PR 限定のテスト影響範囲検出 gate（REQ-019）、完了時点（case-run/case-close）の検証スイート証跡契約（REQ-007-006〜009）、実行配置と検査の詳細（artifact-quality-control-routing Design、quality-gates Design）、原則の確立判断（DEC-024）
