## 目的

7呼出元と case-auto 停止伝播の統合後の横断整合を確認する。QG/HITL 重複、新規永続成果物混入、
case-auto 伝播 regression、責務重複、command 定義本体と Design の Step 表現整合を検証する。
共通契約は REQ-014、各 command 呼出統合は REQ-015 が所有する。
