## 目的

skill rename 実施時の src/opencode/skills ↔ docs/specs/skills 対称性を
deterministic に検査し、rename に伴う参照更新漏れ・node 関係不整合による
手戻りを防止する。

## 要件

| ID | 要件 |
|---|---|
| REQ-026-001 | skill rename を伴う作業手順に src/opencode/skills/{name} と docs/specs/skills/{name} の物理 path 一致検査を追加する。rename 後に両者の path が一致することを deterministic に検証する。 |
| REQ-026-002 | frontmatter id と物理 path の不一致を検出し、warn または error として報告する。 |
| REQ-026-003 | Artifact Graph node 関係の不整合（旧 name node 残存、新 name への関係未更新等）を検出する。 |

## 適用範囲

### 対象
- docs/specs/integrity/targeted-docs-guard-implementation.md（検査観点の追加）
- src/opencode/skills/repo-agentdev-integrity/SKILL.md（検査手続きの拡張）
- skill rename を伴う作業全般

### 対象外
- 配布 skill（src/opencode/skills/agentdev-*）への固定内部 path 持み込み（REQ-002 配布物境界と衝突）
- Artifact Graph の relation モデルそのものの変更
