## 目的

test strategy 設計時点（req-define）で選択される検証手段の質基準として、production-equivalent verification の定義を一般原則として確立する。「常に特定環境でテストする」等のプロジェクト固有ルールではなく、対象リスクに関係する境界の再現性で判定する一般原則とする。

本 REQ は検証手段の質基準を設計時点（req-define）で所有する。REQ-007-006〜009 が所有するのは完了時点（case-run/case-close）の証跡契約であり、時点分担が分かれるため本 REQ は REQ-007 を複製せず参照に留める。

## 要件

| ID | 要件 |
|---|---|
| REQ-055-001 | production-equivalent verification を「本番を完全複製することではなく、対象リスクに関係する実行・依存・環境境界を十分再現した検証である」と定義すること |
| REQ-055-002 | production-equivalent verification の完了時点の証跡契約（検証スイート合格判定、fail 由来分類、検証環境記録、baseline 再生成）は REQ-007-006〜009 が正規所有するため複製せず、参照に留めること |

## 適用範囲

- **対象**: test strategy 設計時点（req-define）における検証手段の質基準、production-equivalent verification の一般原則としての定義
- **対象外**: 完了時点（case-run/case-close）の検証スイート合格判定、fail 由来分類、検証環境記録、baseline 再生成（REQ-007-006〜009）、特定環境でのテスト実施等のプロジェクト固有ルール、変更誘発境界リスク分析の分析契約（REQ-054）
