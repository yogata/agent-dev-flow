## 目的

ADF 管理下の Markdown 全体を対象に、日本語技術文書としての表現と用語選択の基準を統一し、文書ごとの表記揺れと日本語として不自然な英単語混在を解消する。

REQ-001-017〜019 が文の記述様式（文意に基づく自然な日本語・肯定文原則）を所有するのに対し、本 REQ は語の選択・分類・語彙管理の基準を所有する（関心対象で区別）。文章表層品質の検査機構は REQ-053 が、機械検査と意味判断の委譲境界は REQ-053・REQ-010・REQ-036 がそれぞれ現行どおり所有する。

## 要件

| ID | 要件 |
|---|---|
| REQ-094-001 | 人間向けの日本語文章は、日本語として意味が完結し、自然に読める文章であること。英字表記を文章中に残すのは、その表記自体を維持する必要がある場合に限定すること（文の記述様式は REQ-001-017〜019 が所有する） |
| REQ-094-002 | 英語由来で日本語の技術用語として定着したカタカナ語は、日本語表現として扱うこと |
| REQ-094-003 | 対象語は、標準的な日本語で表現する語、定着したカタカナ技術用語、日本語で意味を説明すべき語、原表記を維持する語の4分類で管理すること。各分類の判定基準と語例は文書種別責務 Design の用語政策が所有すること |
| REQ-094-004 | 複数の自然な表現があり得る語は、文脈に応じた表現を選択すること。英単語の排除のみを目的とした不自然な漢語化を行わないこと |
| REQ-094-005 | 直訳やカタカナ化だけでは意味が明確にならない概念は、意味に応じた日本語への置換または文章による説明へ改めること。短い訳語で意味を正確に保持できない場合は、単語を置き換えるのではなく文章そのものを書き換えること |
| REQ-094-006 | コマンド名、Skill 名、API 名、YAML / JSON のキー、列挙値、環境変数、ファイル名、パス、コード上の識別子、外部製品・サービス・標準仕様の正式名称を、本要件の文章是正によって変更しないこと |
| REQ-094-007 | ADF の正式なモデル名・成果物名は変更しないこと。人間向けの日本語文章では、正式名称を裸の英単語として日本語文章へ直接混在させることを基本形とせず、日本語で意味を説明し、正式名称を明示する必要がある箇所だけ正式名称を併記すること |
| REQ-094-008 | 語彙管理は、推奨される日本語表現、定着したカタカナ表現、文脈ごとの使い分け、原語を保持すべき条件、固定置換の可否、文脈判断の要否、文章として説明すべき概念の各区別軸を保持して管理できること |
| REQ-094-009 | 自動的な固定置換の対象を、文脈によって意味の変わらない安全な表現に限定すること。複数の訳語があり得る語、意味が文脈依存する語、文章構造そのものの修正を要する語を、固定置換規則へ含めないこと（機械検査と意味判断の委譲境界は現行 REQ-053・REQ-010・REQ-036 が所有する） |
| REQ-094-010 | docs/ 配下および src/ 配下に存在するすべての Markdown ファイルを本要件の確認対象とすること。過去記録・retired 文書・Report を含み、履歴上その文字列自体を保持する必要がある正式名称、識別子、状態値、事実関係は変更しないこと。本要件による是正は、文章表層品質検査における機械検査対象の拡大を意味しないこと |
| REQ-094-011 | 文章修正の前後で、要件、設計上の意味、状態遷移、契約、失敗時動作、履歴上の事実が変化しないこと |
| REQ-094-012 | 新規または更新される Markdown に対しても本要件と同じ用語選択原則を適用できる状態とし、一括修正のみで完了する仕組みとしないこと |

## 適用範囲

- **対象**:
  - docs/**/*.md および src/**/*.md のすべての Markdown ファイル（現行文書、過去記録・retired 文書、Report、Command / Skill 等の人間向け Markdown、Markdown 内の人間向け説明文、見出し・表見出し・説明ラベルを含む）
  - 用語の表記と ADF 固有名を説明する文章の表現
  - 語彙管理データ（語彙レジストリ実体、プロジェクト用語 prh 辞書）の区別軸構造
- **対象外**:
  - Markdown 以外のファイルの同時全面修正
  - コード上の識別子の日本語化、API 契約の変更
  - YAML / JSON 等のキーや列挙値の名称変更、コマンド名や Skill 名の名称変更
  - ADF の成果物種別やモデルそのものの名称変更、外部製品・サービス・標準仕様の正式名称変更
  - 日本語化だけを理由とした仕様・動作・意味の変更
  - 英語由来のカタカナ技術用語を一律に漢語へ置換すること、未合意の用語への一律の固定訳の新設
  - 文章表層品質検査における機械検査対象ファイル範囲の拡大（REQ-053-039 の歴史記録の扱いは現行維持）
