# ADF判断アーキテクチャ（判断方法・確定権限・人間判断境界）

## 目的

ADF全体の判断を、判断方法（決定的処理・閉じた意味評価・開いた推論の3分類）と判断確定権限（正規契約からの導出・委譲された裁量・人間に留保された判断の3分類）を独立軸とする統一モデルとして定義し、判断の局所所有、判断確定と副作用実行権限の分離、失敗・停止理由の原因別処理、閉じた意味評価の製品非依存化を所有する。旧判断モデル（決定的処理／semantic Skill の二分法、一意性中心の自律確定規則、状態だけに基づく人間判断規則）を置き換え、各ワークフローが個別に保持していた判断規則を少数の共通原則へ統合してADF全体の判断契約を単純化する。

後継Decision（DEC-048）が本要件の判断モデルを採用し、DEC-036決定(1)の二分法を置き換える。詳細な判別基準、確定権限判定表、原因別処理対応表、閉じた意味評価の閉包条件の詳細は foundations/v4-responsibility-boundaries Design が集約所有する。

## 適用範囲

### 対象

- ADFの主要な正規判断の判断方法・確定権限・人間判断境界の横断原則
- req-define、case-open、case-ready、case-run、品質ゲート、case-auto、case-close、case-revise、intake-promote、learning-promote、inspect-promote、backlog-review の各判断境界
- 判断確定と副作用実行権限の分離原則
- 失敗・停止理由の原因別処理
- 閉じた意味評価の製品非依存な定義と閉包条件
- 旧判断モデルの残存除去

### 対象外

- 個別の閉じた意味評価について、評価器だけで最終確定してよいかの実証（T2）
- Jev と LLM の性能・精度・費用・速度比較、確信度閾値の最適化、Jev 以外の具体的評価器の選定、複数評価器の振り分け・合議・自動代替（T2）
- 中央判断ルーター、共通判断台帳等の新規統制基盤
- 結果状態の追加
- 各評価器の実装方式の詳細
- T1 と無関係な既存不整合や古い記述の一般的整理
