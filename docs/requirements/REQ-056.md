## 目的

技術固有知識（リスク判断知識）の恒久所有構造と workflow からの利用契約を確立する。ADF core（配布成果物）は一般規則のみを持ち、技術固有知識（Next.js client/server、Turbo globalEnv、Vercel prerender、Supabase 等のリスク判断知識）を ADF core に埋め込まない。知識は learning から昇華されて成長し、リスク導出規則として次の分析で使われる成長する資産として扱う。

本 REQ が所有するのは技術固有知識の所有面の正本と workflow からの利用契約である。extension 機構・Capability Skill モデルの契約は REQ-002-030/031・REQ-027 が正規所有のまま変更せず、既存 REQ/Design には知識の所有・利用契約としての正本が存在しないため本 REQ を新設する。禁止面の正本は REQ-002 の追加行、所有面の正本は本 REQ として相互参照する（REQ-002-039 の例外条件に適合）。

## 要件

| ID | 要件 |
|---|---|
| REQ-056-001 | 技術固有知識（リスク判断知識）の所有先を、Design（現在のシステム事実）と project-local 側の判断知識（project-local Capability Skill として所有）に分担させること |
| REQ-056-002 | project-local 側の判断知識を workflow 責務へ接続する機構は、REQ-002-030/031 が正規所有する Capability Skill Extension の機構経由とし、本 REQ は extension 機構そのものの契約を所有せず名レベル参照に留めること |
| REQ-056-003 | workflow（変更誘発境界リスク分析を含む）から技術固有知識を利用できること |
| REQ-056-004 | 知識は learning 昇華先ルーティング（REQ-039 のルーティング契約）を経由して project-local 側に流入し、リスク導出規則として次の分析で使われる成長する資産として扱うこと |
| REQ-056-005 | Knowledge 独立文書種別の導入は未決事項として分離し、本 REQ はこれに依存しないこと |

## 適用範囲

- **対象**: 技術固有知識（リスク判断知識）の恒久所有構造、project-local 側判断知識と Design の分担、workflow からの利用契約、知識成長サイクル（learning 流入 → 保管 → 利用）
- **対象外**: extension 機構の配置と読込境界（REQ-002-030/031）、Capability Skill 抽出契約（REQ-027、workflow-skill-model Design）、文書種別の定義（document-type-responsibilities Design）、learning 昇華先ルーティングの契約本体（REQ-039）、配布成果物側の技術固有知識非保持（REQ-002 追加行、禁止面の正本）、Knowledge 独立文書種別の導入判断
