## 目的

agentdev-artifact-graph スクリプト群（parse.ts 等）が対応 YAML 構造を明示し、未対応構造を診断可能とする。代表質問回帰検証（10件）へ実入力を組み込む契約と、実入力 fixture 設計原則を所管する。

REQ-012（Artifact Graph 標準化）が標準化全体を所管するのに対し、本 REQ は parsing-quality 固有を所管する。標準スキルの配置、open extensibility モデル、augmentation 仕様は REQ-012 の対象であり、本 REQ は対象外とする。

## 要件

| ID | 要件 |
|---|---|
| REQ-020-001 | agentdev-artifact-graph の解析スクリプト群（parse.ts 等）が対応する YAML 構造（frontmatter、id、context.paths、rules.skill、checks.skill 等）を明示すること |
| REQ-020-002 | 解析スクリプトが未対応の YAML 構造を検出した場合、構造の種別と出現位置を診断情報として出力できること |
| REQ-020-003 | 代表質問回帰検証（10件）を artifact-graph 解析スクリプトへの実入力として組み込む契約を定義すること |
| REQ-020-004 | 実入力 fixture の設計原則（選定基準、配置先、再現性、機密情報除去）を明示すること |
| REQ-020-005 | 代表質問10件の選定基準を、過去運用での高頻度質問上位10件、または Artifact Graph 経路クラス別（隣接、パス、プロベナンス、発見的抽出）の代表サンプル合計10件上限として明示すること |
| REQ-020-006 | 高位問い合わせの標準候補数上限は、代表ケースによる回帰検証結果に基づいて決定すること。当該回帰検証は代表質問回帰検証（REQ-020-003）の体系に接続して運用し、README 等を経由した既知の候補増幅を再現する回帰試験を含めること |

## 適用範囲

- **対象**: agentdev-artifact-graph 解析スクリプトの対応 YAML 構造の明示、未対応構造の診断、代表質問回帰検証への実入力組み込み契約、実入力 fixture 設計原則
- **対象外**: Artifact Graph 標準スキルの配置と open extensibility モデル（REQ-012）、augmentation 仕様（REQ-012）、LLM による関係抽出の意味推定、外部ベクトルストア等のインフラ実装
