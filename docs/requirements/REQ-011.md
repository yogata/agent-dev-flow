## 目的

AgentDevFlow の外部システム連携を単一の差し替え可能な境界で集約し、配布物の環境依存を排除する。

承認境界、許可・禁止副作用、永続状態、完了証拠の各責務を I/O 境界で一貫して担保する。

GitHub Issue/PR への読み書きと外部実行バックエンドへの委譲を統一された手続きで実現する。

ローカル版との互換性を境界の差し替え可能性で確保する。

配布物が外部連携手段を個別に実装することを防止する。

## 適用範囲

### 対象

agentdev-gh-cli skill を適用対象とする。

GitHub Issue/PR への読み書きを行う command および skill を適用対象とする。

外部実行バックエンドへ委譲を行う command を適用対象とする。

配布成果物の外部連携手段を適用対象とする。

### 対象外

外部連携を行わない内部 command および skill を対象外とする。

本文生成ロジックを対象外とする。

完了判定ロジックを対象外とする。

Epic 依存判定ロジックを対象外とする。

capture 分類ロジックを対象外とする。

harness 固有詳細（agent 名、model 名、必須 skill 名、timeout、retry 等）を対象外とする。

実行計画内部形式を対象外とする。

コード構造・テスト構造を対象外とする。
