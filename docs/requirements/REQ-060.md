## 目的

bun test の実行起点（cwd）とパス指定形式の非統一により、環境依存の失敗やテスト未実行（0 件実行）が繰り返し発生した。bun test の全実行形態を「repo root 起 cwd + `./` 付き相対パス指定」に統一し、逸脱時に実行形態由来であることを検知できるようにする。QG-4 フル suite 正規形（agentdev-quality-gates 正規所有）の所有権は侵食せず、参照・補完に留める。

## 要件

| ID | 要件 |
|---|---|
| REQ-060-001 | bun test の全ての実行（フル suite の 3 cwd 分割正規形に加え、単独実行・ファイル単体指定を含む）について、検査の実行形態（実行ディレクトリ、パス指定形式、依存配置、タイムアウト値）は checker-execution-contracts.md「bun test 実行形態契約」節が所有し、実行形態が統一され逸脱時に実行形態由来であることを検知できることを成果として要求すること（実行方式・具体値の詳細は同 Design を参照） |
| REQ-060-002 | bun test 実行形態由来の逸脱（実行形態不統一、0 件実行、依存解決失敗）を検知できること。検知条件の具体は checker-execution-contracts.md「bun test 実行形態契約」節が所有する |
| REQ-060-003 | bun test 実行形態契約は、QG-4 フル suite 正規形（agentdev-quality-gates が正規所有）の所有権を侵食せず、参照・補完に留まること |
| REQ-060-004 | bun test 実行形態由来の環境依存の失敗・0 件実行の知識が docs/knowledge/ に文書化され、既存の bun test 関連知識と相互参照されること |
| REQ-060-005 | agentdev-quality-gates 配布 references から、bun test 単独実行・ファイル単体指定の実行形態規約（checker 実行契約 Design の該当セクション）への参照が存在すること |
| REQ-060-006 | bun test を正規テストが参照する package 境界ごとに依存が解決可能な状態で実行すること。依存配置・worktree 環境差の具体は checker-execution-contracts.md「bun test 実行形態契約」節が所有し、0件実行・依存不足・不完全な検査を成功扱いしない一般形は REQ-007-006・REQ-007-015 が所有する |
| REQ-060-007 | bun test scripts/ 全体実行（フル suite）を含む検証の委譲プロンプト・実行指示は、実行 timeout を明示指定すること。timeout の標準値・上限値の所有は checker-execution-contracts.md「bun test 実行形態契約」節が所有する |

## 適用範囲

- **対象**: bun test の全実行形態（フル suite、単独実行、ファイル単体指定）の統一と逸脱検知の成果、checker 実行契約 Design の bun test 実行形態契約、bun test 実行形態由来の知識文書（docs/knowledge/）、agentdev-quality-gates 配布 references からの参照。0件実行・依存不足・不完全な検査を成功扱いしない一般形は REQ-007-006・REQ-007-015 が所有する
- **対象外**: QG-4 フル suite 正規形の所有権と記述内容（agentdev-quality-gates が正規所有）、bun test 以外の checker 実行形態、bun test ランナー・スクリプトの実装詳細
