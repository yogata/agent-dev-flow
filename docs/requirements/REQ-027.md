## 目的

複数workflow で共通する能力を Capability Skill として横断的に抽出し、workflow 固有STEP の過剰な共通reference 化を回避する。Workflow Skill の意図しない discovery / invocation リスクに対する soft guard を導入する。代表ケース（case-run / case-auto・req-define・req-save / spec-save・intake-promote）で新workflow モデルの妥当性を検証する。

本 REQ は REQ-002（配布成果物の責務境界）、REQ-005（ワークフロープロトコルと工程接続）、REQ-006（Case実行オーケストレーション）のいずれにも吸収できない独立関心（Capability Skill・Soft guard・代表ケース検証）を所有する。Capability Skill model 詳細は SPEC（`docs/specs/workflows/workflow-skill-model.md`）が正規所有者として定義する。

## 要件

| ID | 要件 |
|---|---|
| REQ-027-001 | 複数workflow で共通する能力を Capability Skill として横断的に抽出し、workflow 固有STEP の過剰な共通reference 化を回避すること。Capability Skill の定義・配置・参照契約は SPEC（`docs/specs/workflows/workflow-skill-model.md`）が正規所有者として定義すること |
| REQ-027-002 | Workflow Skill の意図しない discovery / invocation リスクに対し、OpenCode 1.18.15 で実現可能な soft guard を導入すること。soft guard の実現方法が OpenCode 機能制約により実現できない場合は、代替手段を Findings に記録し対象外とすること |
| REQ-027-003 | 代表ケース（case-run / case-auto・req-define・req-save / spec-save・intake-promote）で新workflow モデルの妥当性を検証すること。検証結果を pass / fail / blocked / not applicable で記録すること。capture-only型（capture・learning 等）・read-only-diagnostic型（inspect-docs・inspect-skills 等）は STEP model 対象外（resume point / export / import を持たない）とし、代表ケースから除外すること |

## 適用範囲

- **対象**:
  - 複数workflow 共通能力の Capability Skill 抽出と過剰共通reference 化の回避
  - Workflow Skill の意図しない discovery / invocation リスクに対する soft guard（OpenCode 1.18.15 実現可能範囲）
  - 代表ケース（case-run / case-auto・req-define・req-save / spec-save・intake-promote）での新workflow モデル妥当性検証と検証結果の pass / fail / blocked / not applicable 記録
  - capture-only型・read-only-diagnostic型の STEP model 対象外宣言
- **対象外**:
  - 配布成果物の責務境界、Command / Workflow Skill / Capability Skill の基本責務分界（REQ-002、DEC-010）
  - ワークフロー protocol、STEP reference 構造、Input Resolution と durable state（REQ-005、DEC-011）
  - Case実行オーケストレーション、case-auto の権威情報源（REQ-006）
  - Capability Skill model 詳細（配置・参照契約・1:N分割基準・依存方向）（SPEC `docs/specs/workflows/workflow-skill-model.md`）
  - harness 固有の ToDo 使用・compaction 検出・current STEP 選択の実処理（DEC-001 context管理harness委譲、REQ-002-022 harness固有詳細禁止）
