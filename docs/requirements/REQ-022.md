## 目的

Artifact Graph 標準配布スキル（agentdev-artifact-graph）の augmentation 配置先を正規化し、SPEC へ明示することで、consumer/self-hosting で一貫した運用基準を確立する。

## 要件

| ID | 要件 |
|---|---|
| REQ-022-001 | Artifact Graph 標準配布スキルの augmentation 配置先として、専用配置（.agentdev/artifact-graph.yaml）を正規配置とし、その選定根拠と適用条件を SPEC（docs/specs/skills/agentdev-artifact-graph.md）へ明示する。 |
| REQ-022-002 | augmentation 配置先と project-extensions 機構（DEC-005、.agentdev/extensions/skills/agentdev-artifact-graph.yaml）は別概念として扱い、両者の責務境界と使い分け基準を SPEC へ定義する。 |

## 適用範囲

- **対象**: docs/specs/skills/agentdev-artifact-graph.md（augmentation 配置先規範の明示）、project-extensions 機構（DEC-005）と augmentation 配置先の関係定義
- **対象外**: 段階3 Issue #1951（Self-hosting 移行）での再評価実施（本要件の対象外、追跡は Issue #1951）、augmentation データ形式そのものの仕様変更
