## 目的

リファクタリング PR で周辺テストが陳腐化する事象の再発防止として、テスト影響範囲を機械的に検出する gate を所管する。
PR 単位で SPEC 変更に連動する関連テストを特定し、陳腐化を検出して不合格時の処置へ渡す契約を定義する。
検出対象と検出契機と不合格時の処置は本 REQ が要件として定義し、判定ロジックの実装詳細は SPEC と checker 実装へ委譲する。

## 要件

| ID | 要件 |
|---|---|
| REQ-019-001 | リファクタリング PR に対してテスト影響範囲検出 gate を実行し、SPEC 変更に連動する周辺テストの陳腐化を検出できること |
| REQ-019-002 | テスト影響範囲検出 gate は検出対象、検出契機（SPEC 変更時の関連テスト特定）、不合格時の処置を明示すること |

## 適用範囲

- **対象**: リファクタリング PR へのテスト影響範囲検出 gate、SPEC 変更に連動するテスト特定、陳腐化検出、不合格時の処置
- **対象外**: テスト自体の実行基盤（CI 等）、影響範囲スキャンの実装詳細アルゴリズム（SPEC、checker 実装所管）
