## 目的

要件定義プロセスは、既存REQ照合、操作分類、反映作業混入防止、ユーザー合意形成を含む一貫した契約である。
本 REQ は req-define プロセスと Definition 保存内部責務（case-ready / case-revise の委譲先 Capability Skill）の横断基本契約を定義する。

## 適用範囲

**対象**:

- req-define コマンド
- Definition 保存内部責務（case-ready / case-revise 委譲先）
- 要件形成プロセス全体
- ユーザー合意形成プロセス
- 既存REQ照合と操作分類の判断根拠の維持、採用範囲の維持、保存結果の再取得と整合確認、中断・部分失敗後の再実行

**対象外**:

- Case 実行プロセス
- Intake と Learning lifecycle
- コード実装
- テスト実行
- 工程駆動系経路（phase 系操作）における反映先判断・採用規律の所有（REQ-110 が所有する。変更駆動経路側の対応は本 REQ が所有する）
