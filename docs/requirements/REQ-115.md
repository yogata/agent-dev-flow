## 目的

case-run scripts 配下（src/common/skills/agentdev-workflow-case-run/scripts/）には tsconfig.json / package.json が不在で型検査基盤が存在せず、宣言のみの未使用定数が長期未検出となる実績がある。case-run scripts 配下への型検査基盤導入の是非と方針を決定として記録し、後続実装要求の判断根拠を提供する。

## 要件

| ID | 要件 |
|---|---|
| REQ-115-001 | case-run scripts 配下への型検査基盤導入方針として、既存15スキルの package 構成パターン（例: agentdev-workflow-case-ready/scripts/tsconfig.json。tsconfig.json + package.json による typecheck 実行構成）に準拠した構成の導入を決定として記録すること |
| REQ-115-002 | 本方針は REQ-112 とは適用領域が異なる旨の注記を含めること。REQ-112 は tools 領域（src/common/tools/）のルート package と local package の二重管理統合方針であり、case-run scripts は二重管理を持たない単独 scripts 領域で構造が異なるため、REQ-112 方針の単純適用としないこと（REQ-112 本体は変更しない） |
| REQ-115-003 | 採用時、bun test 正規形（QG-4 3 cwd 分割実行）の実行経路・検査対象集合が変化しないことを確認条件とすること。tsconfig.json・package.json の実追加、typecheck の品質検査経路組込みの実施、agentdev-quality-gates への型検査水準記載の要否判断は本方針決定の対象外（後続の実装要求）とすること。C20 系参照結線欠落の早期検出効果は noUnusedLocals 等の設定内容に依存する旨を判断材料として記録すること |

## 適用範囲

- **対象**: src/common/skills/agentdev-workflow-case-run/scripts/ の型検査基盤導入方針の記録
- **対象外**: scripts 配下テストの実行形態変更（bun test 正規形）、他 skills scripts 領域の再構成、tsconfig.json・package.json の実追加、typecheck gate 組込みの実装
