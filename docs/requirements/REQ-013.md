## 目的

AgentDevFlow 現行体系から DOC-MAP を完全に除去する。DOC-MAP 廃止は判断事項（Decision）として扱わず、既存 REQ/Decision/SPEC/skill/command/template/guide への DOC-MAP 依存を横断的に削除することで「なかったこと」として整理する。探索経路は Artifact Graph（REQ-012）と README へ統合する。
