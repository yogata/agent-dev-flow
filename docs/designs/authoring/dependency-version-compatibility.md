# 外部依存メジャーバージョン互換性管理ガイド

外部依存のメジャーバージョン互換性管理のガイド。
`docs/specs/guides/` ドメインは存在しないため、執筆規約ドメイン（authoring）へガイド的性質の SPEC として配置する。
依存追加・更新前の互換性事前確認手順、影響範囲スキャン方法、検査器と対象コードのバージョン整合要件を定義する。

## 背景

外部依存のメジャーバージョンアップは互換性非整合を引き起こす事例がある。

- 具体例1: no-excuse 検査器が TypeScript 7 を要求するが対象コードは TypeScript 5.9（起動不能）
- 具体例2: zod v3 → v4 の `.refine` API 非互換

## 依存追加・更新前の互換性事前確認手順

- 依存追加・更新前にメジャーバージョン互換性を事前確認する
- 依存追加・更新前に検査器要件と対象コード要件を突き合わせる

## 影響範囲スキャン方法

- 依存追加・更新前に影響範囲をスキャンし、互換性非整合箇所を特定する
- API 非互換のシグナル（非推奨メソッド、削除メソッド、シグネチャ変更）を検出対象とする

## 検査器と対象コードのバージョン整合要件

- 検査器（no-excuse 等）と対象コードの TypeScript バージョン整合を必須とする
- 検査器が要求するバージョンと対象コードが使用するバージョンが不一致の場合、依存追加・更新を停止する
