# AgentDevFlow v3 憲章

v3.0.0 の目的、対象外、基本原則、管理方式を1ページに要約する。基準は [ADR-001（v3 charter）](../adr/ADR-001-v3-charter.md) であり、本ガイドは基準への導線を提供する。基準と矛盾する記述がある場合は ADR-001 を優先する。

## v3 は何を解決するか

v2.11.0 までに蓄積した過剰統制を削減し、ADF の責務を限定して明確化する。具体的には次を是正する。

- 配布 command の `agent:` 固定など、harness 選定領域への ADF core 侵出
- SPEC への実装詳細侵出（CLI 引数、report スキーマ、fixture 構成等）
- 一度限り移行検査（IR-009/057）と歴史経緯語彙検出の恒久ルール化
- `requirements/mapping-table.md` の現行判断入り口化
- 同じ意味を複数成果物が所有する重複（ADR-011/ADR-011、ADR-001/ADR-011-038 等）

## 対象外

次の実現方法は harness、AI モデル、適用プロジェクトが決定する。ADF は関与しない。

- モデル選定、エージェント選定、サブエージェント階層
- skill の具体的な呼出し
- timeout、retry、context 管理
- TDD、コードレビュー、デバッグの具体的実現
- 実装計画の内部形式、コード構造、テスト構造

ADF は必要能力と標準方針を定義できるが、特定のエージェント名、skill 名、起動 API、実行順序は固定しない。

## 基本原則

### hard governance の限定

工程を停止する機械的強制は、次の8点に限定する。

1. 状態破壊
2. 権限逸脱
3. ユーザー合意の偽装
4. 作業または永続情報の喪失
5. 二重実行、競合更新
6. 誤った成果物の正規化
7. 下流工程の実行不能
8. 後から検出・回復できない重大な失敗

文章品質、推奨実装方法、分類の細部、改善候補は guidance または finding であり、停止条件にしない。

### 新規統制追加の原則

新しい REQ/ADR/SPEC/command/skill/state/schema/gate/必須 field/checker を追加しないことを既定とする。追加を提案する場合は、次の7条件を全て立証する。

1. 再現可能または複数回観測された問題がある
2. 被害が hard control に値する
3. 削除、統合、interface 縮小、guidance 改善では防げない
4. 機械的または運用上、強制できる
5. 正規所有者が一つに定まる
6. 既存の何を削除または簡略化できるか説明できる
7. 将来の削除条件または再評価条件がある

「念のため」「将来必要かもしれない」「網羅性を上げたい」のみでは追加しない。

## 管理方式

| 項目 | v3 における取扱い |
|------|------------------|
| 最終 v2 tag | v2.11.0 |
| 統合ブランチ | `v3/rebuild`（cutover 時 `main` へ反映） |
| v2 保守 | 停止（tag 参照のみ） |
| prerelease tag | なし（直接 v3.0.0） |
| REQ/ADR 番号 | `REQ-001〜`、`ADR-001〜`（v2 は `v2:REQ-0119` 等で区別） |
| docs 配置 | 現行配置を維持（`docs/requirements\|adr\|specs\|guides`） |
| Local backend | 必須範囲に維持、仕様は最小契約へ縮小 |
| draft 形式 | 案B（承認済 change brief）へ縮小 |

## cutover 条件

v3.0.0 のリリースは次の全てを満たした場合のみ行う（詳細は ADR-001 決定6）。

- charter 原則を満たす
- 基準文書が自足している
- 実行物が v3 基準と整合する
- 必須シナリオ（10件）が通る
- v2 互換範囲が明確
- active v2 作業の扱いが決着している
- one-time 成果物の移管漏れがない
- migration note がある
- main へ統合可能、v3.0.0 tag を付与可能

## 利用者の読み方

- 個別の REQ/ADR/SPEC/command/skill/template/script/checker は、本 charter の原則へ照らして位置づく。
- 「この統制は本当に必要か」を判断する際は、まず hard governance の8点に該当するか、次に新規統制追加の7条件を立証できるかを検討する。
- 該当しない場合は guidance・finding・reference へ降格する候補とする。
