# DEC-024: 変更誘発境界リスク分析の導入と検証契約への投影

## 背景

変更対象 artifact 種別ベースの品質管理では、変更によって変化する依存・実行・環境境界
（dependency boundary、client/server boundary、execution boundary、build/runtime boundary、
environment propagation boundary）のリスクが実装差分から事前に導出されず、
QG-4（最終受入）で初めて発見される状態が残っていた。
shared package 変更が server 設定 API 依存経路の変化を経て client 側の実行失敗に至る
ような、境界をまたぐリスクを品質プロセスの第一級入力として扱う必要がある。

## 決定

1. 変更から境界リスクを導出する変更誘発境界リスク分析を ADF の品質プロセスに導入する
2. 導出した case-specific risk を検証契約へ投影すること
   （change → risk → verification obligation → test strategy）を品質プロセスの
   第一級入力とする
3. 本 Decision は原則の確立に限定する。実行配置と検査詳細は REQ/Design へ委譲する
4. hard 統制点とはしない

## 関連

- REQ-054（変更誘発境界リスク分析の要件）: 決定 1、2 の要件面の正規所有者
- artifact-quality-control-routing Design: 投影入力源の拡張（case-specific risk の追加）
- quality-gates Design: QG-1 のリスク→test strategy 投影完全性検査観点

## 結果

変更誘発境界リスク分析と検証契約への投影が原則として確立される。
実行配置と検査詳細の権限は REQ/Design に留まり、新規の機械強制ゲートは追加されない。
