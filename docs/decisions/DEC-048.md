# DEC-048: ADF判断アーキテクチャ: 判断方法・確定権限・人間判断境界の統一モデル

## 背景

ADFでは、決定的処理と意味判断の責務分離、委譲時の判断・承認境界、閉じた意味評価の実証、
各ワークフロー固有の自律確定条件が異なる時期・目的で段階的に導入された。判断や停止の
根拠として「決定的処理か意味判断か」「一意に確定可能か」「fail・partial・blocked 等の
結果状態」等の異なる基準が併存し、判断の難易度・確信度・結果状態・処理種別が人間判断の
必要性と混在している。各ワークフローに局所的な判断規則が蓄積し、同じ意味の判断境界が
異なる表現で所有されている。

## 決定

既存 Decision との差分として次を決定する。

(1) ADFの判断方法を3分類（決定的処理: 入力と確定済み規則から一意に導出できる処理／
閉じた意味評価: 必要な事実、判断基準、結果空間を評価前に限定でき、その入力だけで判断
可能な意味判断で、評価入力の構成に別の未解決意味判断を隠さない／開いた推論: 結果空間を
事前に完全には限定できない推論）として採用する。3分類を難易度順の段階構造としない。
これにより DEC-036 決定(1) の「deterministic 処理／semantic 判断」二分法を置き換える。

(2) 判断結果を確定してよい主体の区分を判断方法から独立した軸として採用する（正規契約
からの導出／委譲された裁量／人間に留保された判断）。判断の難易度、モデルの自己申告に
よる確信度、評価器間の不一致、fail・partial・blocked 等の結果状態、意味判断であること、
一意解でないことを人間判断の根拠としない。人間に留保する判断は、新しい目的、価値、
優先順位、対象範囲、外部契約、受け入れ条件、恒久規範、または既存正規契約だけでは解決
不能な規範間の優先関係を確定する必要がある場合に限定する。

(3) 具体的な正規判断の所有は各ワークフローが局所的に維持する。判断ごとに正規所有者、
証拠提供主体、補助評価・助言主体、最終確定主体を必要に応じて区別する。横断判断ルーター、
共通判断台帳、評価器の動的振り分け等の中央判断機構を新設しない。adversarial-review 等
の補助推論は最終確定権限を自動的に取得しない。

(4) 判断内容を自律確定できることと、確定結果に基づく副作用を自動実行できることを別
契約として扱う。判断の自律化によって既存の明示的な破壊操作承認や安全境界を迂回しない。
副作用実行権限・並行性・冪等性の所有は DEC-039 が維持する。

(5) 失敗・停止理由を結果状態だけではなく8原因（実装不具合、証拠不足、外部依存障害、
運用上の前提不足、上流成果物の投影・整合不備、正規情報源間の解決可能な不一致、正規情報源
間の未解決規範矛盾、人間に留保された新しい判断）で区別し、原因に応じた処理（自動回復、
再試行、証拠再取得、正規所有工程への差し戻し、手動による運用上の介入、人間の権限判断）
を使い分ける。既存の結果状態を追加しない。

(6) 閉じた意味評価を ADF の判断能力として定義し、特定評価器固有の質問型、確信度、確率
形式、評価器名を ADF の恒久契約に必要以上に含めない。現在の Jev 先行評価と LLM 最終判断
の逐次経路は実証・観測段階の契約とし、ADF 全体の恒久的な最終確定原則としない。複数評価器
の同時使用、動的切替、自動代替、合議を先行導入しない。個別評価器の実力・安定性・実観測を
根拠とする最終確定主体の変更は別途実測（T2）を経て判断する。

(7) DEC-036 決定(2)（Harness/Backend adapter 境界）および決定(3)（Project Extensions
の semantic extension point としての位置づけ）は DEC-036 のまま維持する。本 Decision の
置換対象は決定(1) の判断二分法に限る。

## 結果、影響

各ワークフローが個別に保持する判断規則（個別HITL規則、一意性中心の自律確定規則、状態
だけに基づく人間判断規則、評価器固有語彙の上位露出、重複判断層）が少数の共通原則へ統合
され、ADF全体の判断契約が単純化される。DEC-036 決定(1) を引用する正典は本 Decision の
分類へ参照を更新する。詳細な判別基準・判定表は foundations/v4-responsibility-boundaries
Design が集約所有し、要件水準の原則は REQ-096 が所有する。
