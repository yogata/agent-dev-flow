# Decision: 実験前提の恒久運用原則の採用と移行完了後レガシー資産の扱い境界

## 決定

1. 本リポジトリの変更は実験として扱い、ロールバックは Git 履歴による復元で対応する。対照表・バックアップ資産などの防衛的恒久資産の維持を移行・整理の前提条件としない。
2. 後方互換性を維持しない。旧表記・旧パス・旧契約への移行補助層（crosswalk、Baseline、マイグレーションスクリプト）を恒久資産として維持せず、LLM/スクリプトによる一括直接修正を標準手段とする。履歴性は Git 履歴で担保する（DEC-013 と同一の方針）。baseline 機構の撤廃は検査ルール自体の廃止を意味しない: 存続検査（IR-055・IR-059・IR-073 等）は baseline による免除管理・delta 運用を失った後も検出器として存続し、検出違反は直接修正で解消する（DEC-014・DEC-006 が定める IR-059 の範囲・経路は維持される）。
3. 測定不能を理由とする停滞を排除する。再評価条件が実測不能・確定不能のままの保留（測定待ち）を禁止し、測定待ち案件は「仮説の即時導入」または「完全削除」の二択で即決する。完全削除処分は処分理由の明示をもって決済記録とし、黙認と区別する。
4. 原則3の適用範囲は狭義とする。deferred 機構（REQ-038-006）と blocked 機構（REQ-120）そのものは存続させ、「測定待ちを理由とする保留」のみを禁止する。DEC-027 の観測ベース評価ループ（実測してから縮小判断）と矛盾しない。測定がないことのみを削除理由とする広義解釈は採用しない。
5. DEC-056（ADF v5 移行と互換性の境界）との適用時間軸の区別: 移行実行中は DEC-056/REQ-109 の意味保存・検証義務が優先する。移行完了後のレガシー資産には本原則を適用し、対照表・baseline 等の恒久維持義務を負わない。DEC-056 の決定内容（後方互換非必須・意味保存移行・検証不足時の成功宣言禁止）は本原則と同方向であり、本 Decision は DEC-056 を覆すものではない。

## 背景

- 実験前提の3原則（実験・ロールバック許容、後方互換性完全破棄、測定不能停滞の排除と二択即決）を採用し、レガシー移行資産（crosswalk・migration 系 Design/スクリプト）、integrity 検査の baseline・免除・廃止語彙・旧パス・retired 検出の各機構、.agentdev 実行証跡、測定待ち記録を完全削除処分する計画（Phase 1〜5 一括実行）が利用者承認済みである（要件定義 AG-001〜AG-013）。
- DEC-056 の「移行元情報を破壊せず・検証可能に・未処理情報の処理継続」と本原則（crosswalk 等の中間資産削除・測定待ち停滞排除）の間の意味的緊張は、DEC-056 本文に「crosswalk 等の移行記録の恒久維持」を定めた条項が存在せず、意味保存・検証が移行プロセス中の義務であるため、条項衝突ではなく適用時間軸の区別問題と判定した（決定事項5）。DEC-056 は supersede・部分置換とも行わず accepted 維持・relates-to 接続とする。
- REQ-003-024（学習成果物の deferred・未処理は自動削除対象から除外）と REQ-038-002/006（deferred 機構の維持・自動削除禁止）と learning 測定不能系項目の空初期化の間の緊張は、原則3を狭義解釈とし、learning 空初期化は workflow の自動削除ではなく本要件定義に基づく利用者指示の明示決済として実行する位置づけで解消した（決定事項3・4。REQ-003-024 と REQ-038-006/007 は文言修正せず維持）。
- IR-055・IR-059 を baseline 削除と一体でルール削除する案は、両 IR が移行補助層でなく現行の enforcement 層である点で DEC-014（IR-059 の範囲・経路を確定し後続決定へ委ねない）・DEC-006（IR-059 を IR-056 へ統合しない）と衝突し、REQ-010-084 の IR-073（ng-baseline 撤廃・ルール存続）との扱いとも不整合になるため採用しない（決定事項2。削除対象は計画明示の8ルール〔IR-009/014/021/046/054/057/065/066〕のみ）。

## 代替案と選択根拠

1. IR-055・IR-059 を baseline 削除と一体でルール削除する案 — 却下。両 IR は現行の enforcement 層であり、DEC-014・DEC-006 が定める IR-059 の範囲・経路の維持と整合しない（決定事項2）。
2. 測定待ち機構（deferred・blocked）自体を廃止する広義解釈 — 却下。REQ-003-024・REQ-038-006・REQ-120 と衝突し、DEC-027 の観測ベース評価ループと矛盾する（決定事項4）。
3. crosswalk・baseline 等の移行補助層を恒久維持する現状維持 — 却下。利用者が実験・ロールバック許容と後方互換性の完全破棄を恒久運用原則として採用した（決定事項1・2）。
