# DEC-047: textlint 依存実体の版固定情報解決への転換

## 背景

agentdev-textlint-guard plugin は third-party 成果物の実体（vendored engine bundle 約 1.5MB、kuromoji 辞書 約 17MB）を git 管理し全配布経路へ同梱してきた。ライセンス実測（2026-09-29）では、依存パッケージ群は MIT だが bundle 内に LICENSE 文が 0 件（copyright 表記 6 件のみ）、kuromoji は Apache-2.0（LICENSE-2.0.txt 同梱が再配布条件）、mecab-ipadic 辞書は著作権表示の複製物包含を要求する独自ライセンスであり、リポジトリが public である以上 clone / ソース ZIP / release archive の全経路が再配布に該当する。配布者がライセンス遵守義務を一方で負う構造を解消する。

## 決定

1. agentdev-textlint-guard plugin の third-party 依存実体（vendor/textlint-engine.bundle.json、vendor/kuromoji-dict/）を git 管理と全配布経路から除外し、版固定情報（package.json + bun.lock）のみ配布する。
2. 依存実体は利用者による導入時再生成（bun install と bun run build:engine）で構築する。導入系スクリプトは欠落検知と fail-closed 案内のみを行い、生成もネットワーク取得も行わない。DEC-016 の禁止対象は導入系スクリプトであり、利用者実行の依存解決手順（導入時のネットワーク取得を含む）はその適用対象外であることを明示する。
3. DEC-028 の決定のうち「配布前に依存を解決した成果物を供給し、導入先での追加パッケージ取得を必要としない」条項について、textlint guard 依存実体の配布供給の範囲に限り置換する。DEC-028 の直前の DEC-016 維持宣言および他の決定（textlint 採用、書込み前検査と最終検査の共通化、DEC-001 決定3 の限定例外、7条件維持）はすべて維持する。版固定は bun.lock と build スクリプトの固定で維持されるため、DEC-028 の目的（同一検査の再現性）は失われない。
4. 再配布ライセンス是正（バンドル内ライセンス文書不在の解消）と、依存とライセンス種別を宣言する THIRD-PARTY-NOTICES による通知保持を配布モデルの一部とする。release archive は依存実体を含まず、通知文書を同梱する。
5. 本 Decision は上記範囲に限る後継判断であり、DEC-028 の過去の本文を意味変更して上書きしない。関係は frontmatter relations の supersedes（部分置換）で宣言し、DEC-028 側の frontmatter superseded_by へ後継を記録する（双方向参照整合）。

## 代替案

repo-local Plugin 化（案A）は consumer が書込み前検査・最終検査を失うため不採用。runtime を node_modules 直読みへ切替（案B2）は既定検査構成への影響が過剰なため不採用。plugin 実体ごと repo 外へ分離（案C）は自作コードにライセンス問題がなく、third-party 取得機構（DEC-023）は Skill 用のため不採用。いずれの代替案も offline-first の縮退（導入時ネットワーク前提の復活、offline 保証の「導入時解決完了後の実行時」への限定）を解消しない。B1 はこの縮退をライセンス是正とのトレードオフとして受容する。

## 結果と影響

REQ-029-012/013 が版固定情報解決の依存契約と通知文書保持を所有する。REQ-053 の導入時生成手順行が導入時生成手順の契約へ改定され、当該手段行は後の REQ-053 手段分離で textlint-quality-runtime.md 依存と配布節（REQ-029-012 とともに）へ移管されている。consumer 導入には導入時の依存再生成手順（ネットワーク取得を含む）が必要になる。offline 環境では導入時解決が完了するまで textlint 検査は検査不能として fail-closed 扱いとなる。git 履歴に残存する blob の完全除去（history rewrite）は対象外とする。
