# DEC-057: 工程駆動コラボレーションモデル（検討テーマ・外部検討・段階形成）の採用

## 背景

v5.1.0 は変更駆動に加えて工程駆動を追加し、工程の設計を別セッション・外部AI検討で段階的に育て、最新の正規成果物群から全体像を再構成できるようにする。旧 phase-plan の追加候補提示は次工程の初回テーマ形成へ統合する（案A）。

## 決定

検討テーマの正本と導出一覧の単一正本原則、外部AI検討の仲介モデル（持出しは利用者確認・無断送信禁止・既知機微情報の無断混入禁止、戻りは貼付・ファイル両受理で採用根拠は利用者明示判断または有効な正規決定のみ）、正規成果物への増分形成と閲覧像の第二正本化禁止、外部AI戻り入力の非機能受け入れ条件（線形走査 O(n)・採用件数比例の証跡量・fail-closed）を採用する。工程テーマ作成・外部検討を変更駆動の必須前処理としない。

## 結果、影響

工程駆動コラボレーションの利用契約は新規 REQ-110 が所有し、REQ-106/107 の差分・追跡義務を再定義しない。採用規約の4状態解決は REQ-104-008 へ追加する。操作の入出力手順・保存構造・実行主体は Design（v51-phase-driven-collaboration-model）が所有する。
