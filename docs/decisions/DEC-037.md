# DEC-037: Traceability の Change / Evidence 中心への再中心化

## 背景

DEC-017（最小トレーサビリティモデル）と DEC-030（トレーサビリティ標準機能への一般化・producer/consumer 境界）により sidecar/policy/checker 機構は整備された。一方、運用上の主な問いは「今回の Change が何に影響したか」「acceptance を何の Evidence で満たしたか」「再検証すべき範囲は何か」であり、全 artifact の恒久的完全グラフ維持は目的ではなく手段になっていた。

## 決定

Traceability の主目的を Change と Evidence へ再中心化する。「この要求は何によって設計・実装されているか」「今回の Change はどの要求・判断・設計へ影響したか」「acceptance/requirement を何の Evidence で満たしたか」「変更時に再検証すべき関連範囲は何か」の 4 問いに答えることを主目的とし、global completeness は診断・影響分析の必要性から再設計する。

DEC-030 の sidecar/policy/producer-consumer 機構は、永続情報として価値がある範囲で拡張して搬送する（本 Decision は機構の廃止ではなく、中心の移動と必要永続情報/導出可能情報の分離を決定する）。現行形式を前提とせず、v4 の意味モデルから形式を再導出する。Case/Change の Evidence と impact を第一級とする。TIM の処遇は crosswalk で記録する。

## 結果、影響

後続の Traceability 実装（RU §24）は完全グラフ維持ではなく 4 問いへの回答能力を第一の設計基準とする。

## 関連する決定

- relates-to: DEC-017（最小トレーサビリティモデルの採用と Artifact Graph の廃止）。TIM の中心を Change/Evidence へ移動する
- relates-to: DEC-030（トレーサビリティ標準機能への一般化と producer / consumer 境界の確立）。sidecar/policy 機構は拡張して搬送し、中心のみ移動する
