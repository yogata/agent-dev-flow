# DEC-060: ADF本体の GitHub Release 記録と公開承認境界

## 背景

DEC-059 は追加公開成果物について「Custom Tool カタログに含まれない操作はワークフローが準備（リリースノート草稿・対象確認）までを行い、公開権限の確認後に所定経路で実行する」と定めた。ADF 本体で版タグごとの GitHub Release 記録を整備するにあたり（2026-10-16 RU-0228 合意）、草稿作成・読み戻しまでを workflow 実行範囲に含めるための規則変更が必要となった。

## 決定

(1) DEC-059 決定(1) のうち「公開操作」規則を次のとおり部分置換する。一般規則（追加公開成果物はプロジェクトの採用方式に従う）は維持する。ADF本体の採用方式として、GitHub Release の草稿作成と読み戻し確認を workflow 実行範囲に含め、実行経路は Custom Tool 操作カタログ（agentdev_gh）に限定する。カタログ操作の入力契約に公開モードを含めない。承認境界は副作用の有無ではなく公開の有無によるものとし、公開（draft の publish 化を含む）は利用者が草稿作成とは別に明確に認めた場合に限る。

(2) 版番号規則、正式リリースの基準、リリース条件、完遂済み・リリース保留、タグ権威・不移動は DEC-059 / DEC-039 のとおり維持する。

(3) カタログへの追加は Release 草稿作成・Release 読み戻しに必要な機能のみとし、操作契約（custom-tool-contracts Design）と操作カタログ列挙の契約テストを同時更新する。

## 代替案

「準備」の解釈拡張として非意味変更で扱う案（GitHub 上の草稿作成は WRITE 副作用の実行であり準備に含まないため不採用）。草稿も公開操作とみなし作成まで利用者実行とする案（GitHub の draft Release は write 権限保持者のみ可視であり公開物ではないため不採用）。

## 結果、影響

REQ-114-010、REQ-114-016、REQ-114-017 に適用する。stage 7 リリース（backlog-auto）と agentdev_gh 操作カタログが対象。
