# ADR-006: inspect 3-command 構成への正規化

## 背景

REQ-010-014 は公開 inspect command 集合を {inspect-docs, inspect-skills, inspect-promote} の3件と規定する。
しかし ADR-005（Project Extensions Architecture）の適用結果として inspect-extensions が第4の公開 command として存在し、REQ-010-014 と実際の command 構成が乖離していた。

extension 検査の責務は次の3層へ分解可能である。
- deterministic check（機械的検査）: YAML 構文、必須 field、配置規則等
- semantic diagnosis（意味診断）: 責務境界、上書き意図等
- finding disposition（処分）: promote、defer、reject

これら3層はそれぞれ docs-check（+IR-056）、inspect-skills、inspect-promote の既存 command が所有する能力と重複する。

## 決定

inspect-extensions を独立公開 command として廃止する。
公開 inspect command 集合を REQ-010-014 の3件へ戻す。

extension 検査の責務を次の11行へ一意に割り当てる。

| 検査または処理 | 正規所有者 |
|---|---|
| extension一覧 | IR-056 / docs-check |
| YAML構文 | IR-056 / docs-check |
| 必須セクションとfield | IR-056 / docs-check |
| kindと配置 | IR-056 / docs-check |
| IDと対象commandまたはskillの対応 | IR-056 / docs-check |
| context path実在 | IR-056 / docs-check |
| 委譲先skill実在 | IR-056 / docs-check |
| 旧.agentdev/doc-inputs/** 残存 | IR-056 / docs-check |
| extension責務境界 | inspect-skills |
| 標準commandまたはskillを上書きする意図の意味診断 | inspect-skills |
| findingのpromote、defer、reject | inspect-promote |

- self-hosting full audit では docs-check が .agentdev/extensions/{commands,skills}/*.yaml を走査する
- consumer 側では case-run と case-close の changed-path routing が .agentdev/extensions/** 変更時に IR-056 を起動する
- deterministic check、semantic diagnosis、finding disposition の三層は重複しない
- inspect-docs へ extension の意味診断を追加しない

## 結果、影響

- ADR-005（Project Extensions Architecture）は本 ADR により superseded となる。
  ADR-005 自体の直接編集は行わず、本 ADR が後継として扱う（RU-0026 契約、accepted ADR の意味変更は後継 ADR）。
  ADR-005 の status を superseded へ変更し、superseded_by に本 ADR を明示する。
- IR-059（distribution reference boundary）は本 ADR の対象外とし、検出対象、severity、gate level、責務境界を変更しない。
  IR-059 を IR-056 へ統合しない。
- inspect-extensions の accepted SPEC、SPEC index、command 実体、skill 参照、README、DOC-MAP の導線は retire または更新する。
- 既存の inspect-extensions を呼び出していたスクリプト、ドキュメント、運用手順は後継 command（docs-check、inspect-skills、inspect-promote）へ移行する。

## 関連する決定

- ADR-005（Project Extensions Architecture）: superseded。本 ADR が inspect-extensions 廃止と責務移管を確定し、後継として扱う。
- ADR-001 決定4（新規統制追加の原則、憲章）: relates-to。本 ADR は inspect command 集合を憲章原則へ整合させ、command 増加を抑制する。
- REQ-010（自己監査と診断・是正候補抽出）: relates-to。REQ-010-014 が公開 inspect command 集合の3件へ正規化を要件とし、本 ADR がその判断根拠となる。
