# grep 0 件基準の機械検査と旧語の字面引用の衝突を避ける執筆規約

## 知識内容

是正注記・「後継」注記・旧→新対応表のいずれも旧語の字面を本文に残すため、「旧名（旧表現）が 0 件であること」を要求する grep 0 件基準の完了条件・機械検査と構造的に衝突する。この衝突は執筆時点で予見可能であり、検査設計や exemption で事後解消するより執筆規約で予防する方が低コストである。取り扱いは次のとおりである。

1. 旧表現を禁止する是正注記は、禁止対象の字面を引用せず描写形（「X を権威情報源とする旧表現」等）で書く。
2. 削除・RETIRE・supersede を伴う参照張替えでは、「旧〜の後継」形式の注記を本文に残さず、対応関係は正本（crosswalk・処遇記録）へ集約して本文は正本参照のみを持つ。
3. 歴史参照テーブル（旧→新行対応表等）の旧行 ID・旧名は code span 等、検査の対象外形式で記録する。
4. grep 0 件基準の完了条件を持つ Case では、注記・対応表を含む全体 grep を case-run と case-close の両方で実施する。

## 適用条件

- 横断是正・用語統一・Design 削除（RETIRE/supersede）・参照張替えを伴う変更の執筆場面。
- grep 0 件基準の完了条件・機械検査を持つ Case の検証手順。

## 適用対象

- docs/ 配下の正規成果物（REQ/Decision/Design/guide）の本文・注記・対応表。
- 検査側（grep 0 件基準・IR）の実装変更は対象外（exemption 設計は別議論）。
- 履歴文書（superseded Decision 本文・crosswalk 処遇行・歴史記述）の正当クラス残置は対象外。

## 根拠

- case 2979（2026-09-19）: 4 Design 参照張替えで「後継」形式の注記が grep 0 件検査と衝突（残存 55 → 注記除去後 22、内訳は正当クラス）。「後継」注記を全除去し、対応関係は crosswalk へ集約して本文から旧名を排除した。
- 2026-08-15 横断是正（PR #2111 系・旧 deferred エントリより統合）: 禁止対象の旧表現の字面をそのまま引用した禁止注記が、完了条件の再 grep で hit し「旧表現 0 件」基準と衝突。描写形への言い換えで解消。同一問題クラス 2 事例の集約知識化。
