# 知識（Knowledge）

docs/knowledge/ はプロジェクト知識（プロジェクト固有の再利用可能な判断材料）の正規配置領域である。
所有と workflow 利用の契約は [REQ-056](../requirements/REQ-056.md) が正、配置基準の執筆時判断は [document-type-responsibilities Design](../designs/responsibilities/document-type-responsibilities.md) を参照する。
本 README は領域の案内であり、知識文書そのものではない。

## 配置規約

- 1知識1 Markdown ファイルとする（REQ-056-001）
- ファイル名は kebab-case の slug とし、固定 ID 採番を持たない（REQ-056-001）
- frontmatter は title、created、updated を必須とする（patterns Design「Knowledge frontmatter 規約」）
- 本体は知識内容、適用条件、適用対象、根拠、関連知識の5項目を備える（REQ-056-003）
- 知識文書は独立文書種別であり、REQ/Decision/Design への ADF-COVERS 宣言を持たない（patterns Design「Knowledge frontmatter 規約」）

規約の詳細は上記の正規参照先を確認し、本 README では複製しない。
