## 変換の方式

- 手順記述: `## workflow` の STEP 列挙を前出出力検証表（工程・前提条件・出力契約・検証基準の表形式）へ置換した。推奨順は工程ラベル（STEP-N。旧 `工程-N` ラベルは順序ラベル様式是正で `STEP-N` へ統一済み）と表の行順で保持する
- G 番号: 硬い境界（課金・認証・破壊的操作・state 破壊・書き込みスコープ・承認境界等の否定規則）に限定して付番し、工程上の選好は肯定形の不変条件（`## 不変条件`）へ集約した
- 旧 G 番号の扱い: 生存した硬境界規則は元の番号を維持する（相互参照整合の保全）。統合先・不変条件化先は本表が所在を明示する
- Workflow Skill 側 `references/` の STEP resume point 構造（8要素）は変更していない。旧 G 番号への参照は生存番号参照・「command 不変条件」参照・「前出出力検証表」参照へ更新した
