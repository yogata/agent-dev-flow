# 構成移行（migrate）

利用プロジェクトの .agentdev/ 配下の構成を、導入済み AgentDevFlow 配布版の正規構造へ移行する人間向け公開入口である。
移行は、版別差分仕様と最新の正規構造一覧に基づく推論移行と、決定論的事後検証に分離して実行する。
チェックアウトの取得・更新とプロジェクション配置自体は install.ps1 の責務であり、本コマンドは導入済みチェックアウトに対する構成移行を担う。

## 入力

- 移行の指示（自然言語。省略時は検知結果から対象を解決する）
- .agentdev/install-state.json の記録版とチェックアウトの src/common/VERSION の差分
- install.ps1 -Mode check の出力（旧構造痕跡・版不一致・未移行の検知結果）

## 出力

- 移行の結果（適用した差分仕様、旧新対応、引き継いだ情報とその内容・処理状態、削除した旧痕跡、決定論的検証の結果）
- 移行不能・要判断事項は、不足する情報とユーザー判断の内容を分離した報告

移行が決定論的検証で成立を確認できるまで、本コマンドは完了を示さない。検証不成立は成功として扱わない。

## workflow

本コマンドは workflow 実装本体を `agentdev-workflow-migrate` スキルへ委譲する。
版別差分仕様の解決、旧構造痕跡の検知、移行の実行、削除判断のユーザー確認、決定論的検証は同スキルの制御平面が所有する。
本コマンドは単独で起動でき、他のコマンドを前置しない。通常ワークフローの初期化に依存しない。

## 不変条件

- 構成移行は、版別差分仕様と最新の正規構造一覧に基づく推論移行と、決定論的事後検証に限る
- 引き継ぐ情報の内容と処理状態を維持する（解釈変換しない）
- 移行の完了は、決定論的検証が成立した場合に限って示す
- 旧配置の削除はユーザー確認を受けてから実行する

## ガードレール

- install.ps1 と通常コマンドに移行処理・互換シムを持たせない（移行は本コマンドが単独所有する）
- 旧パスへのフォールバック読み書きを行わない
- 情報損失を伴う削除をユーザー確認なしに実行しない
- REQ、Decision、Design 等の正規成果物の内容を変換しない
- 検証不成立を成功として報告しない
