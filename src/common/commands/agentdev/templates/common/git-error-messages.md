# Git エラーメッセージテンプレート（共通）

複数コマンドで使用する Git 同期、Push エラーの構造化メッセージ形式。

## Git 同期エラー（pull --ff-only 失敗）

```
## Git 同期エラー

**エラー種別**: pull --ff-only 失敗
**停止理由**: リモートに未取り込みの変更があり、fast-forward マージできない
**対象ブランチ**: {current_branch}
**ユーザーアクション**: 手動で `git pull --rebase` または `git stash && git pull --ff-only && git stash pop` を実行してください
**raw git output**:
{git_error_output}
```

## Git Push エラー

```
## Git Push エラー

**エラー種別**: push 失敗
**停止理由**: リモートへのプッシュに失敗
**認証起因分類**: {認証失敗 | 対話要求 | タイムアウト | 非認証起因}
**対象ブランチ**: {current_branch}
**変更ファイル**: {changed_files}
**必要な処置**: {認証起因時は認証設定の確認・修正等の処置、非認証起因時は手動 push 等の処置}
**再開条件**: {認証起因時は認証設定の修正後に当該手順を再実行 等}
**ユーザーアクション**: 手動で `git push` を実行してください（非認証起因時）
**raw git output**:
{git_error_output}
```

### push 失敗の認証起因分類

push 失敗時は、エラー出力を次の3分類に判定し、上記形式の「認証起因分類」へ記載する。判定できない場合は「非認証起因」とする。

| 分類 | 判定の手がかり |
|---|---|
| 認証失敗 | `Authentication failed`、`403` / `401` 等の認証拒否を示す出力 |
| 対話要求 | credential helper による対話 UI の起動、terminal prompt 要求、ユーザー入力待ちでの停止 |
| タイムアウト | 接続・認証のタイムアウト出力、完了しない待機の検出 |

- **認証起因時の扱い**: 認証支援の待機を正常実行として扱わない。push は失敗として扱い、必要な処置（実行環境側の認証設定の確認・修正、必要な人間の認証操作）と再開条件（認証設定の修正後に当該手順を再実行）を構造化エラーで報告して停止する。待機の継続で復帰を試みない
- **同一条件での再試行禁止**: 認証条件を変更しない同一条件での長時間待機を無条件に再試行しない。認証方式を変更して再試行する場合は、変更内容と結果を識別できる形で検証記録へ残す。認証方式の選定は特定のコマンドに固定せず、環境側で非対話実行可能な正規の経路から選択する
- **秘密値不出力**: 分類判定と報告の際、資格情報の値（トークン、パスワード等）を raw git output を含む証跡・ログへ出力しない。出力に credential 値が含まれる恐れがある場合は該当箇所を伏せた上で証跡へ残す

認証の設定・選定規律の正規所有者は実行環境側であり（AGENTS.md「ハーネス選定」の非対話認証参照行と実行環境知識文書 `docs/knowledge/git-noninteractive-auth.md`）、本テンプレートは認証の設定・修正手順を所有せず、失敗の分類と報告までを扱う。

## 使用方法

各コマンドは上記形式をインラインで保持せず、本テンプレートを参照して同一形式でエラーを表示すること（準拠）。
