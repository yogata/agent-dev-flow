# migrate workflow スキル

migrate command の workflow 実装本体である。
適用元の状態（記録版・観測された旧構造）から適用すべき差分仕様を解決し、推論移行を実行し、決定論的事後検証で成立を確認する制御構造を所有する。
本スキルは移行の技術的失敗を成功として扱わず、検証が成立しない限り移行の完了を示さない。

migrate command は公開 interface（入出力契約・ガードレール）と本スキルへの dispatch のみを持ち、本スキルが workflow 実装本体を提供する。

## 入力

- migrate command から渡される移行の指示（自然言語。省略時は検知結果から対象を解決する）
- 現在の会話コンテキスト

## 出力

- 移行の結果（適用した差分仕様、旧新対応、引き継いだ情報とその内容・処理状態、削除した旧痕跡、決定論的検証の結果）
- 移行不能・要判断事項は、不足する情報とユーザー判断の内容を分離した報告

完了報告の必須要素の規律は、`agentdev-workflow-lifecycle` スキル「共通報告・Decision・自律確定規約」節「完了報告の必須要素」を正本として参照する。

## 副作用

- .agentdev/ 配下の旧配置から新配置への移動・改名、旧痕跡の削除（削除はユーザー確認後）。移行が変更する範囲は対応表の移動・改名と identity.yaml のキー改名に限り、それ以外の文書の内容は更新しない
- install.ps1 -Mode check の実行（決定論的事後検証）
- Decision、REQ、Design 等の正規成果物は更新しない

## workflow model（STEP model 対象外）

本スキルは対話操作完結型の workflow であり、STEP model の対象外である。
resume point / export / import を持たない。各移行操作が1完結単位であり、移行の実態（.agentdev/ 配下の配置）が durable state であるため、中断後の同一要求再実行では実在配置の再観測から現状を再構成する。

| 工程 | 名称 | 内容 |
|---|---|---|
| 1 | 現状把握 | install-state.json の記録版とチェックアウトの src/common/VERSION を読み、版差分を特定する。install.ps1 -Mode check を実行し、旧構造痕跡・版不一致・未移行の検知結果を取得する。実行基盤の内蔵ツールで .agentdev/ 配下の実在配置を観測する |
| 2 | 差分仕様の解決 | references/version-deltas.md から、観測した旧構造に対応する差分仕様を解決する。適用対象の差分が存在しない場合は移行不要として決定論的検証のみを実行する |
| 3 | 移行計画の提示とユーザー確認 | 適用する差分、移動・改名の対応、削除対象とその内容を提示し、ユーザーの確認を受ける。削除を伴わない移行でも移行内容の確認を求める |
| 4 | 移行の実行 | 対応表に従い、旧配置から新配置へ情報を移す。引き継ぐ情報の内容と処理状態を維持する |
| 5 | 旧痕跡の削除 | ユーザー確認済みの削除対象を実行する。削除しない選択があった場合は痕跡を残し、決定論的検証は不成立として扱う |
| 6 | 決定論的検証 | 工程 1 の install.ps1 -Mode check が版の記録がない旨を報告した場合は、install.ps1 -Mode apply の実行をユーザーに案内し、実行の完了を確認する（導入済み版の記録は install.ps1 が行い、移行操作では install-state.json を作成・更新しない）。install.ps1 -Mode check を再実行し、版一致・旧痕跡不在・検証合格を確認する。検証が成立しない場合は移行の完了を示さず、未成立部分を報告する |
| 7 | 報告 | 適用した差分、旧新対応、引き継いだ情報、削除結果、検証結果を報告する。旧新対応には、移行で更新されずに残る文書とその旧名称から現行名称への対応を含め、ユーザーの更新が必要な範囲として案内する |

ファイル検索・内容検索・ディレクトリ列挙は実行基盤の内蔵ツール（ファイル検索、内容検索、読み取り）を使用し、bash 内蔵コマンド（grep、ls 等）を標準手順としない。install.ps1 -Mode check の実行は上記の決定的検証経路の呼出しであり、この限りではない。

## 差分仕様の解決

適用する差分仕様は references/version-deltas.md を正本とする。
観測した旧構造（install.ps1 -Mode check の検知結果と .agentdev/ 配下の実在配置）から必要な差分を選択する。
version-deltas.md に記述のない旧構造を観測した場合は、それを移行せず、観測結果と対応する差分仕様が存在しない旨を報告する（推測で対応表を作らない）。

## 正規構造の参照

移行先の正規構造は references/target-structure.md を正本とする。
本ファイルは配布版が正とする構造の一覧であり、個別プロジェクトの永続・非永続境界の記述は適用先の .agentdev/README.md が担う。両者の役割を混同せず、移行は構造一覧に従う。移行で更新されずに残る文書と、ユーザーが更新する範囲に必要な旧名称と現行名称の対応は、references/version-deltas.md の「移行で更新されない文書」に従い、結果報告で案内する。
