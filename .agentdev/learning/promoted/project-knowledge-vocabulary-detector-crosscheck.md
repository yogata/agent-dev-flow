# baseline-known 違反の一般化置換語彙と検出器パターンの突合

## 背景

IR-055 baseline-known strict 違反の解消作業で、内部 ID を含む語を一般化表現に置換する際、置換後の語彙選択が検出器のパターン定義と突合されず、新規違反を生む事象が発生した（case 2766: 置換語「repo-local」が `repo-*` 検出パターンに該当）。

## 問題

- 一般化置換の語彙選択時に検出器パターン（`repo-*` 等のプレフィックス系）との突合が行われないと、置換自体が新規違反になる
- baseline 運用を持つ他の検査器（IR-059 等）の解消作業でも同様に発生し得る

## 望ましい変更

一般化表現への置換作業時に (1) 置換候補語彙を検出器パターン定義と事前突合する、または (2) 置換後に当該検査を必ず再実行して新規違反 0 を確認する、いずれかを手順に組み込む。fix-and-reverify（1 回で解消）の運用として標準化する。

## 対象範囲

- 対象: baseline-known 違反の一般化置換解消作業、baseline 運用を持つ検査器（IR-055、IR-059 等）の解消作業
- 対象外: 検出器パターン定義自体の変更、baseline の再生成運用
