# RU-0127: 同期委譲実効判定の observed-time 原則注記

## Sources

- `existing-countermeasure-update-sync-delegation-observed-timeout.md`: Case #3139 の TS-004 subset 測定（DEL-3139-1）で全 corpus 1 単位の同期委譲が 5分 timeout で失敗。実装の選択基準どおり非同期委譲へ切替して完遂し（背景子 Abort 対策経路の実証を含む）、観察と委譲収束実績は TS-003 pass の根拠として保持。「同期委譲で完了できる単位」の実効判定が事前見積もりに依存し、環境 timeout の実観測を判定基準とすることが運用文書に明示されていない（ユーザー決定 2026-09-25: 固定数値閾値は定義しない）。

## Source Summary

REQ-036-031（REQ-036.md:50 実読確認済み）は同期/非同期の選択基準を規定するが、「同期で完了できる単位」の実効判定を環境 timeout の実観測に置く指針（observed-time 原則・事前見積もりに依存しない・固定数値閾値を設けない）が運用文書に明示されていない。環境依存の数値断定は環境が変わると陳腐化する。選択基準自体は実装済みであり、運用文書への注記追加で閉じる（ギャップ分類: guardrail insufficiency）。

## 統合理由

1:1。委譲方式の実効判定運用という独立した関心領域。RU-0126（測定対称性・REQ-036-032/033 の検証契約行）と由来 Case が同じでも、成果（測定規律 vs 委譲方式判定基準）と対象行が異なるため分離する。

## 要件化の方向

- 同期/非同期委譲の選択を扱う workflow（inspect-docs 等の診断系・委譲収束系）の reference に、実効判定の実観測基準（observed-time 原則）と固定数値閾値なしの注記を追加する
- 同期失敗 → 非同期切替経路が機能することまで含めて検証する運用を明示する
- REQ-036-033（単一実行の測定値から改善率を断定しない）との整合を維持する
- 対象外: REQ-036-031 の契約変更、harness timeout 設定の変更、固定数値閾値の定義
- 暫定分類は挙動Design。req-define で最終確定する
