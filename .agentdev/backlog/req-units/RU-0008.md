# record-comments applySection の末尾セクション境界におけるセクション後コンテンツ保全（RU-0008）

## 目的

Case Issue 本文の進行状況セクションを `record-comments.ts` の applySection で置換する際、文書末尾に後続する工程記録 HTML コメント群（履歴コメント）が消失しないよう、境界検出の改善または手順上の保全確認を確立する。

## 背景

Case Issue 本文の進行状況セクションを applySection で置換した際（case-close STEP-5-2 本文結果セクション更新・Case #3725）、セクション境界から次の「## 」見出しが現れない区間（文書末尾に続く工程記録 HTML コメント群）までをセクション内容として消費し、履歴コメント（case-run 停止記録・case-revise・case-ready・再委譲記録）が本文から消失した。消失した履歴コメントは復元済み（実害 1 回・復元済み）。既存対策確認は fix gap（内容保持条項 L41 と applySection の末尾境界挙動の不整合に対する前置確認・境界改善の規定なし）。

## 問題

`cleanup-and-capture.md` L41 の STEP-5-2 条項「既存セクションの順序と内容は保持する」が内容保持の意図を宣言する一方、applySection の境界検出実装（次の「## 」見出し行まで走査、endIndex 初期値 `lines.length`〔L210 実測〕）は、置換対象セクションが文書末尾（後続見出しが存在しない位置）にある場合、見出し無しで後に続く HTML コメント群を前セクション内容の一部として消費する。条項の意図と実装の間に不整合があり、かつ applySection 適用前のセクション後コンテンツ保全確認を規定する手順が case-close references に存在しないため、同じ条件（文書末尾セクション置換）で再発し得る。
