# bash heredoc バックスラッシュ転送層消費の追補（第3機構）

## Sources

- `existing-measure-update-heredoc-backslash.md`（learning・worktree-operations.md 破損回避節 + docs/knowledge/windows-git-bash-inline-content-corruption.md）: harness の bash コマンド転送層が heredoc 内容のバックスラッシュをエスケープ解釈して除去する（shell エスケープではなく転送層の処理のため quoted heredoc でも防げない）。JS 正規表現リテラルのバックスラッシュで SyntaxError 2回発生（Root Case #3407・Definition PR #3408）。既存の破損回避節・知識文書は argv escape 解釈と heredoc 打切りの2機構のみ記載。第3機構として「quoted heredoc でもバックスラッシュは転送層で保護されない。バックスラッシュを含むスクリプト・設定ファイルは heredoc 経由で書き込まず、バックスラッシュフリー実装（String.fromCharCode(13)・文字クラス内バックスラッシュなし正規表現・行配列走査）または base64 等の中間エンコード経由で伝達する」を追記。
