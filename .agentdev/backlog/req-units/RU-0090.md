# RU-0090: Draft Definition PR の draft 解除経路整備（Tool カタログと責務定義の空白解消）

## Sources

- **learning: draft 解除の正規経路不在**: Case #2895（Definition PR #2896）で case-ready の pr_merge が HTTP 405（Pull Request is still a draft）で blocked 停止。raw gh pr ready による迂回は agentdev-gh-write-guard 違反のため実行不可、ユーザー手動操作で解消。問題: (1) agentdev_gh 操作カタログが draft→ready 遷移（pr_ready 等）をカバーしない (2) draft 解除責務が case-open と case-ready の間で未定義 (3) write-guard 下で Tool カバレッジ外の GitHub side-effect に正規手段がない。解決選択肢: (a) case-open で非 Draft PR 作成へ変更 (b) case-open または case-ready へ draft 解除責務を定義 (c) agentdev_gh へ pr_ready 追加（write-guard 許可リスト同期含む）。選択は req-define の変更影響分析に委ねる。制約: write-guard の fail-closed 設計は維持、blocked → ユーザー操作 → 冪等再開の暫定経路は整備まで有効。
