# RU-0031: adversarial-review 発動契約非該当時の判定理由記録様式の整備（silent skip 回避）

## Sources

- **非発動時の判定理由記録様式の不在（Case #2831 / #2832、PR #2876 / #2877 を含む Batch 10 Case）**: adversarial-review の発動契約（default-on、skip policy、adapter の発動条件判定）は存在するが、条件非該当でスキップする際に判定理由を記録する様式・義務が規定されていない。(a) case-close の対応記録コメントテンプレート（issue_comment_bug_record.md 系）に adversarial-review の判定欄がなく、検証差分テーブルに行が存在しない case が「未実施」と誤認され得る、(b) 委譲 prompt の default-on 指示と Issue 本文の発動契約「該当なし」が不一致になる委譲で、非発動の判断根拠が委譲先に伝わらず silent skip になる、の2局面がある（2026-09-16 実査: テンプレートに adversarial 判定欄なし、adapter reference に非発動記録の要求なし）。実行時は非発動 case も「発動契約非該当（対象: bugfix/maintenance の機械検証中心、合意形成対象なし）」を対応記録へ明記し、代替としての自己反証（却下案・緩和策・unresolved なしの確認）を実施・記録する運用で有効性を確認済み。

## Source Summary

条件非該当でのスキップを「レビュー未実施」と区別できるよう、非発動時の判定理由記録を様式・義務として整備する。発動条件判定・再 review 条件の正は adversarial-review Design が所有し、本要件は記録様式の整備に留める。

## 統合理由

1:1。単一成果物・単一論点（非発動時の記録様式整備）であり、統合・分割不要。

## 要件化の方向

work_type: maintenance:

1. workflow-templates の対応記録コメントテンプレート（issue_comment_bug_record.md 系）へ adversarial-review の判定欄（発動 / 非発動+理由）を追加する
2. 委譲 prompt 作成手順（case-run references）へ「adversarial-review の発動条件は Issue 本文の実行契約を正とする」を明記する
3. agentdev-case-run-execution-adapter の adversarial-review 統合 reference へ、非発動時は PR 本文（case-run 委譲）または対応記録コメント（case-close）へ判定理由の記録を必須とし、代替としての自己反証（却下案・緩和策・unresolved なしの確認）の実施・記録を様式化する

制約: adversarial-review 自身の審議プロトコル・発動条件の変更は対象外（adversarial-review Design が正規所有）。発動契約セクションを持つ Issue テンプレート（issue_desc_child.md / issue_desc_feature.md）の構造変更も対象外。対応記録コメントは case-close が単一書き手となる運用を維持する。

受け入れ条件: 対応記録コメントテンプレートに adversarial-review の判定欄（発動 / 非発動+理由）が存在すること、委譲 prompt 手順に「発動条件は Issue 本文契約を正とする」旨が明記されていること、非発動時の判定理由記録が必須化され、非発動 case でも対応記録・PR 本文から実施有無と理由が確認できること。
