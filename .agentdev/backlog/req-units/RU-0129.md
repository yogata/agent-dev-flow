# RU-0129: agentdev_jev observation_write completion schema 表示乖離の解消

## Sources

- `existing-countermeasure-update-jev-observation-write-schema-mismatch.md`: Case #3139 の case-ready STEP-5 Jev 観測完成書込みで、公開 schema 定義の required 表示（run-level フィールド群）に従う payload が「unknown completion observation field: durationMs / confidence / inputs / judgmentKind」の invalid_input（retryable: false）で 4回連続拒否。実際の受理条件は schemaVersion + judgments[].llmFinalJudgment / llmTreatment（judgmentId 付き）の最小 payload のみ。partial レコード JSON 実物との差分比較で必要フィールドを特定し成功。根本原因は completion モード（observationId あり）の実装 allowlist（LLM final-judgment 関連のみ）と公開 schema 表示（完全 observation 形を required 表示）の乖離。

## Source Summary
