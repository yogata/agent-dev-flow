# RU-0015: adversarial-review caller 対象コマンド集合の不整合是正

## 目的

adversarial-review caller integration の対象 command 集合について、正規要件である REQ-015 と active な正規文書・配布物・runtime reference の間に存在する不整合を解消する。

REQ-015 を caller 対象集合の正とし、現行実行時に参照されるすべての記述を次の7 commandへ統一する。

- req-define
- inspect-promote
- intake-promote
- learning-promote
- backlog-review
- case-open
- case-run

case-auto は adversarial-review caller ではなく、下位 caller からの停止・decision・resume を扱う orchestration 経路として維持する。

## 対象

- active な adversarial-review SPEC
- `agentdev-adversarial-review` SKILL と references
- REQ-015 caller integration を参照する command SPEC / command 定義
- caller integration を参照する domain skill SPEC / SKILL / references
- workflow / delegation contract における caller / orchestration 表現
- case-auto の caller / non-caller 表現
- caller 対象集合を保持または検査する checker、test、index、registry 等が存在する場合の整合確認
- 配布境界に含まれる実行時成果物の横断整合

## 対象外

- REQ-015 の caller 対象集合または意味の変更
- caller 対象 command の追加・削除
- adversarial-review の default-on / skip policy への変更
- adversarial-review 内部 protocol の強化
- case-auto の parent decision resolution 追加
- caller ごとの既存 review 挿入位置、戻り先、finding 反映責務の再設計
- 歴史的 PR、Issue、commit message、過去作業記録の書き換え
- active 実行時に正規情報として消費されない retired / historical 資料の一括修正

REQ-015 に存在しない caller 集合を他成果物側で独立した正規定義として新設してはならない。表現上 caller 一覧を再掲する必要がある場合も REQ-015 と意味一致させる。

## 要件化の方向

### 1. caller 対象集合

adversarial-review の caller 対象は REQ-015 の以下7 command とする。

1. req-define
2. inspect-promote
3. intake-promote
4. learning-promote
5. backlog-review
6. case-open
7. case-run

### 2. caller ではない command

少なくとも以下を adversarial-review caller として扱わないこと。

- req-save
- spec-save
- case-close
- case-update
- case-auto

case-auto は caller ではなく、下位 command の adversarial-review 由来の停止・decision・resume を扱う orchestration 経路とする。

### 3. 不整合是正範囲

- 特定の既知 SKILL 1ファイルだけを直して完了としてはならない。
- active な正規文書、配布物、SKILL、reference、command 定義、domain skill、workflow contract、および caller 集合を保持する機械検査対象を横断して不一致を確認すること。
- REQ-015 と異なる caller 一覧、USE FOR / DO NOT USE FOR、呼出境界、経路表現が存在する場合、REQ-015 と整合させること。
- historical / retired な記録だけに旧集合が存在する場合、現行実行や正規判断に影響しないことを確認した上で修正対象外としてよいこと。

### 4. 非回帰

- caller 集合是正のために REQ-015 本文の意味を変更しないこと。
- 既存7 caller の review 挿入位置、戻り先、finding 採否・反映責務を変更しないこと。
- case-auto を新しい caller へ変更しないこと。
- caller 集合の正規所有者を複数化しないこと。

### 作業仮定

- REQ-015 の7 caller は現行要件として正しい。
- 現行不整合は正規要件の欠陥ではなく、下流文書または配布物への反映漏れ・古い記述残存として扱う。
- ファイルごとの表現差は許容するが、意味上の caller 集合は REQ-015 と一致させる。
