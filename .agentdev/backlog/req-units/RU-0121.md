# RU-0121: LLM 判断から Jev への置換（Issue C）

## 対象

- 承認された判断単位について `Jev → 最終判断` 経路へ切り替える実装。基本契約は:

```text
Jev
 ↓
confidence >= 採用閾値
 ├─ yes -> Jev を最終判断として利用
 └─ no  -> LLM へ fallback
```

- confidence 採用閾値の適用（閾値の値は Issue B の観測結果から判断単位ごとに決定されたものを使用。本 Issue では新たに決定しない）
- 置換後の Jev 最終判断範囲と LLM 維持範囲の明示（観測記録の該当 judgment にも反映）
- 置換対象判断の Workflow / Skill 側契約更新（最終判断所有を LLM から Jev へ移した判断に限る）
- 置換後も観測（`unchanged / corrected` に代わる最終判断の記録、confidence、outcome）を継続する
