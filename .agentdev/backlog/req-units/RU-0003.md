# RU-0003: bun test 実行形態の統一（repo root 起 cwd・`./` 付きパス指定）

## Sources

- **bun-test-execution-conventions（case 2766/2768/2777/2779、計5件発生）**: bun test は REPO_ROOT を cwd からの相対解決で求めるテストを含むため、scripts 配下等 repo root 以外を cwd にすると環境依存 fail が発生する（case 2768: 8 fail / 4 errors、全件環境依存。repo root 起で 2565 pass/0 fail）。またパスフィルタは `./` 付き相対パスとして解決されるため、`./` なしの `.opencode/...` 表記では no test files matched となり 0 件実行になる（case 2779）。worktree では node_modules 欠落が同時リスク。QG-4 フル suite 正規形（3 cwd 分割実行）は規定済みだが、単独実行・ファイル単体指定時の規約は未整備（load miss）。

## Source Summary

bun test の実行起点（cwd）とパス指定形式の非統一により、環境依存 fail・テスト未実行（0 件実行の見逃し）が繰り返し発生している。実行形態を「repo root 起 cwd + `./` 付きパス指定（ファイル単体指定も含む）」へ統一し、逸脱時の検知条件を併記する規約が必要である。

## 統合理由

1:1。単一成果物で単一論点（bun test 実行形態の統一）であり、統合・分割の必要がない。

## 要件化の方向

checker 実行契約への明記を主軸に要件化する。反映先は `docs/designs/integrity/checker-execution-contracts.md`（bun test 実行形態契約）:

1. bun test 実行形態として「repo root 起 cwd + `./.opencode/...` 形式（ファイル単体指定も `./` 付き）」を明記する
2. 逸脱時の検知条件（REPO_ROOT 解決系テストの fail、no test files matched 出力）を併記する
3. QG-4 フル suite 正規形の所有権（agentdev-quality-gates）を侵食しない。正規形への参照・補完に留める
4. 知識文書化（docs/knowledge/）と配布 references（agentdev-quality-gates QG-4 関連）からの正規形参照を反映候補に含める
