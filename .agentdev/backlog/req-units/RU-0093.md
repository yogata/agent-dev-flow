# RU-0093: ADF-COVERS(implementation) 宣言付与の責務定義と Definition 品質検査への確認組込み

## Sources

- **learning: 宣言付与責務の不在と予防体制の欠如**: ADF-COVERS(implementation) 宣言付与は case-run トレーサビリティ契約上の実行担当の標準責務だが、(1) Case #2898: 委譲プロンプトの抑制文言（declare ONLY rows the artifact genuinely implements）が過度に狭く働き実装 REQ 行への宣言が行われず traceability check の missing-implementation 検出で差し戻し（DEL-2898-002、9ファイルへ宣言付与で解消）(2) Case #2917: 新規 REQ CREATE を含む Definition PR #2919（REQ-087）で宣言付与責務が case-open/case-ready のいずれにあるか明文化されず、宣言欠落のまま merge され case-run で補完（PR #2923）(3) REQ 行 APPEND と新規 REQ CREATE で宣言対象成果物の範囲が異なる点も未整備（deferred L1771 を統合）。検出側（agentdev-traceability check）は既存だが予防側（委譲指針の正の義務、Definition 品質検査の確認項目）が不在。望ましい変更: case-run delegation 指針へ「実際に実装する REQ 行への宣言付与は標準責務」を正の義務として明記（inventing 抑制は「実装しない行を宣言しない」限定）、case-open/case-ready の Definition 品質検査へ artifact_actions で宣言した成果物の ADF-COVERS 宣言存在確認を組込み。

## Source Summary

## 統合理由
