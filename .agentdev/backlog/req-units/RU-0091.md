# RU-0091: project root 外・一時領域書込みブロックに対する正規回避手段の運用指針整備

## Sources

- **learning: guard と正規作業経路の運用指針不整合**: project root 外書込みを fail-closed で拒否する guard 群（agentdev-textlint-guard、distribution-boundary-guard、配布依存境界 pre-write gate）が設計どおり動作する一方、正規回避手段が文書化されていない。(1) AGENTS.md 推奨一時ディレクトリ C:\WINDOWS\TEMP\opencode への write/edit ツール書込みが agentdev-textlint-guard で一律ブロック（Case #2898）(2) 一時 worktree 内編集も project root 外パス検査でブロック（Case #2903/PR #2910）(3) 配布ソース面パス列挙を含む補助ファイル・一時検証ドライバの TEMP 書出しも配布依存境界系 gate でブロック（deferred L1004/L1889/L1364 の同種事象、統合評価対象）。回避手段（node writeFileSync 明示 utf8、worktree 内配置、一時ファイル不要化）の集約文書化なし。望ましい変更: AGENTS.md 一時ディレクトリ推奨への「write/edit ツール不可、node writeFileSync（明示 utf8）経由」注記、worktree 配置先と worktree 内編集の標準手段明記、guard 種別ごとのブロック条件と回避手段の集約知識。制約: guard の fail-closed 設計は維持（緩和ではなく運用指針側で対応）。
