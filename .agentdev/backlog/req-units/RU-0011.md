## Source Summary

Windows の PowerShell で `Out-File -Encoding utf8` を使うと BOM 付き UTF-8 が生成され、git commit メッセージが化ける。対策として BOM なし UTF-8 での書き出し（`node fs.writeFileSync` 等）を commit メッセージ作成手順に組み込む必要がある。
