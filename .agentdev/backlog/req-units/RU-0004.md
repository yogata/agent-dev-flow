# 工程記録の未観測時刻に対する境界表現様式の提供

## Sources

- `.agentdev/learning/promoted/progress-record-unobserved-time-boundary-notation.md`: case-auto stage 3 の工程記録取りまとめ反映時、子 Issue 6件の進行状況（開始・終了日時）を実着手・完了確定の実測なしに PR 作成時刻からの逆算で書込み、case-run 段階（完了判定を所有しない）で終了日時を設定。書換えも record-comments.ts の構築・検証関数を経由しない raw 正規表現置換で行った。復旧後 6件を実測事実に基づく記録へ置換し、case-close の完了確定時に実測終了日時のみを設定して訂正（実害1回・ユーザー確認あり）。工程記録契約（開始日時=初回実着手の実測値のみ・終了日時=completed 確定時のみ設定。issue-lifecycle-records.md L43）は既存だが、観測できない時刻を明示できる境界表現（既知の上限・下限時刻の併記）の様式サポートが record-comments.ts に不在（様式語 grep 0件・adversarial-review A2 実測）で、raw 置換を選択させる間接要因となった。

## Source Summary

未観測時刻を「記載しない」契約（L43）は維持した上で、既知の境界時刻（ブランチ作成・初回 commit・PR 作成等の観測事実）を併記する境界表現の様式が不在。様式サポートの不在は捏造的記録と raw 本文書換えの間接要因となる。境界表現は様式の拡張であり契約違反の正当化ではない点が前提。

1:1（統合・分割なし）。単一根因（未観測時刻の境界表現様式サポート不在）に対する単一の変更要求である。
