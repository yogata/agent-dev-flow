## Source Summary

promoted 成果物の evidence path を Case Issue 本文へ絶対パスで記録する構成は、prune 後に参照不能となり tombstone も残らない。path 単独の参照は case-revise・監査での証跡追跡を弱める。prune 側の証拠保存方針（元learning item / 根拠セクションへの保存）は規定済みだが、参照側に prune を跨ぐ代替識別子の併記規約がない（ギャップ分類: guardrail insufficiency）。REQ-018-006/007 は case-close の判断根拠の凝縮先であり、本 RU の主題（記録規約）とは非重複である。

## 統合理由

1:1。evidence 記録規約（参照側）という独立した関心領域。RU-0124（委譲時の証跡受領経路・記録側）と問題型が異なり、テンプレート・記録規約系として分離する。
