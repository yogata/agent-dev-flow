# inspect 3-command構成への正規化

## Sources

- REQ-010はinspect-docs、inspect-skills、inspect-promoteの3 commandを規定する。
- acceptedのinspect-extensions SPEC、command実体、参照導線、ADR-005には第4 commandが残る。

## Source Summary

inspect-extensionsを独立公開commandとして廃止し、決定的検査をIR-056とdocs-check、意味診断をinspect-skills、finding処分をinspect-promoteへ移管する。
ADR-005は直接編集せず後継ADRで置換し、IR-059の配布参照境界を維持する。

## 目的

公開inspect commandをREQ-010の3件へ戻し、extension検査の実行経路と責務所有者を欠落なく維持する。

## 対象

公開inspect commandは次の3件とする。

1. inspect-docs
2. inspect-skills
3. inspect-promote

責務を次の11行へ一意に割り当てる。

| 検査または処理 | 正規所有者 |
|---|---|
| extension一覧 | IR-056 / docs-check |
| YAML構文 | IR-056 / docs-check |
| 必須セクションとfield | IR-056 / docs-check |
| kindと配置 | IR-056 / docs-check |
| IDと対象commandまたはskillの対応 | IR-056 / docs-check |
| context path実在 | IR-056 / docs-check |
| 委譲先skill実在 | IR-056 / docs-check |
| 旧`.agentdev/doc-inputs/**`残存 | IR-056 / docs-check |
| extension責務境界 | inspect-skills |
| 標準commandまたはskillを上書きする意図の意味診断 | inspect-skills |
| findingのpromote、defer、reject | inspect-promote |

## 対象外

- IR-059の配布参照境界をIR-056へ統合しない。
- inspect-docsへextensionの意味診断を追加しない。
- ADR-005を意味変更の直接編集で処理しない。

## 正規所有者とアンカー

- 正規所有者: REQ-010
- 関連所有者: REQ-001、ADR-005、IR-056、IR-059
- `docs/specs/commands/inspect-extensions.md`
- `src/opencode/commands/agentdev/inspect-extensions.md`
- inspect SPEC index、commandまたはskill参照、README、DOC-MAP
- `docs/specs/integrity/rules/IR-056-project-extensions-integrity.md`
- `docs/specs/integrity/rules/IR-059-distribution-reference-boundary.md`

## 依存関係

RU-0022とRU-0026に依存する。
ADR-005の後継処理はRU-0026の契約確定後に行う。

## 要件化の方向

self-hosting full auditではdocs-checkが`.agentdev/extensions/{commands,skills}/*.yaml`を走査する。
consumer側ではcase-runとcase-closeのchanged-path routingが`.agentdev/extensions/**`変更時にIR-056を起動する。
inspect-extensionsのaccepted SPEC、SPEC index、command実体、skill参照、README、DOC-MAPをretireまたは更新する。
ADR-005はinspect-extensions廃止を記録する後継ADRで置換する。

## 決定的受け入れ条件

1. 公開inspect command集合が`{inspect-docs, inspect-skills, inspect-promote}`と一致し、要素数が3である。
2. 上表の11行が一つの正規所有者だけを持つ。
3. self-hosting full auditとconsumer changed-path routingの両方でIR-056を実行できる。
4. inspect-extensionsのSPEC、index、command実体、skill参照、README、DOC-MAP上の現行導線が存在しない。
5. ADR-005の後継ADRがinspect-extensions廃止と責務移管を記録する。
6. IR-059の検出対象、severity、gate level、責務境界が変更されない。
7. deterministic check、semantic diagnosis、finding dispositionの三層が重複しない。
