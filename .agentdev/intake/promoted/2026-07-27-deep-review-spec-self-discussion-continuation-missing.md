# agentdev-deep-review SPEC の自律審議継続欠落

## 観測内容

`docs/specs/skills/agentdev-deep-review.md` は、RU-20260726-01 AG-009 で合意した「関連コンテキストから判断可能な限り自律審議を継続する」という肯定表現を明記していない。
継続時に試みる前提確認、根拠確認、誤解解消、適用範囲の限定、部分合意の探索、代替案の比較、追加証拠による再評価、批判内容の再構成という 8 手続きも列挙していない。
未解決争点をユーザーへ返す条件は論理的な対偶だが、TS-005 が要求する肯定表現と手続き列挙を満たさず FAIL となった。

## 影響

振る舞い契約の正典である SPEC だけでは、自律審議を継続する条件と試行内容を判断できない。
実装詳細側に手続きが存在しても、SPEC と配布物の契約が一致しない。

## 課題

自律継続の肯定的な義務と、継続時の 8 手続きを SPEC に反映する必要がある。

## 既存要件、仕様との関連

- `docs/specs/skills/agentdev-deep-review.md`
- `docs/requirements/REQ-003.md` の REQ-003-032
- RU-20260726-01 AG-009
- PR #1832、Issue #1830、Epic #1828

## 対応方向

SPEC に「自律審議継続」セクションを追加し、肯定表現と 8 手続きを記載する。
完了条件の不足と同じ spec-update で処理できる。

## 発生源

PR #1832 の Findings / Capture候補 F-1。
