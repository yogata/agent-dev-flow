# 配布物内 3 桁行参照と IR-055 検出方針

## 観測内容
IR-055 の部分マッチ誤検出は修正されたが、配布物内の `REQ-017-017` 等の 3 桁行参照は正規パターンの対象外として残る。

## 影響
配布物内部 ID の残存を検出対象とするか否かが不明確で、全除去方針と検出器の責務境界が曖昧になる。

## 課題
IR-055 Design で 3 桁行参照を検出対象にするか対象外と明記するかを判断する。対象化する場合は配布物横断のプレースホルダー化を別途扱う。

## 既存要件・正規成果物との関連
Issue #2559、PR #2583、REQ-017-017、IR-055 正規パターン定義。
