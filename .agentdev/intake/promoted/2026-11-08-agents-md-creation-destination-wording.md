# AGENTS.md の「作成先確認の制約（作成ヘルパーの機械検査に接続）」文言の現行化

## 観測内容

- Case #3966（PR #3976）で作成ヘルパーの実行経路が撤去された。リポジトリ直下 AGENTS.md（repo-local・配布対象外・検出範囲外）には「作成先確認の制約（作成ヘルパーの機械検査に接続）」に言及する文言が残存する。
- AGENTS.md は REQ-119-007 の「Design 正本本体・実装は変更対象外」の射程外の repo-local 文書であり、Case #3966 の実行 PR では対象外とした（RA-002 または別途整理とされた）。

## 影響

- リポジトリのガイドレール（AGENTS.md）が撤去済み機構（作成ヘルパーの機械検査接続）を現行の規約として記述し続け、エージェントの行動規範として誤適用され得る。RA-002（#3970）のモジュール撤去時に一体で整理するのが低コストと判断されていたが未実施。

## 課題

- AGENTS.md の作成ヘルパー関連文言を、現行の受け入れ評価接続・後片付け責任（REQ-118）の文言へ現行化する。RA-002（#3970）のモジュール撤去時に一体で整理するのが低コスト。
