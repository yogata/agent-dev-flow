# skill SPEC 共通見出し「提供する判断・操作」の中黒はテンプレート由来の定型

## 観測

skill SPEC 共通見出し「提供する判断・操作」の中黒（・）は `_template.md` 由来の定型であり、7 SPEC で共用されている。個別 SPEC では固定複合名詞扱いとして是正対象外と判断された（PR #2266 の TS-QC-001 判定）。

## 今回扱わない理由

PR #2266（Issue #2224）の機械是正では、テンプレート側の判断が本体であるため個別 SPEC 側は是正対象外とした。テンプレート自体の変更はスコープ外。

## 影響

機械判定（中黒検出）が template 由来見出しで毎回許容例外として扱われる。テンプレート側を直さない限り恒常的な例外運用が続く。

## レビューで決めること

- テンプレート `_template.md` 側の見出し文言変更（中黒を含まない形式へ）を実施するか、現行見出しを定型例外として機械判定の許容リストへ明示するか
