# agentdev-deep-review SPEC の完了条件欠落

## 観測内容

`docs/specs/skills/agentdev-deep-review.md` は、RU-20260726-01 AG-013 で合意した完了条件 8 項目を列挙していない。
既存の「合意条件」は争点単位の閉じ方を定義するが、審議全体の完了条件ではない。
固定観点の全 PASS や形式的な同一判定を完了条件としないことも十分に明示されていない。
case-run の TS-007 はこの不足により FAIL となった。

## 影響

振る舞い契約の正典である SPEC だけでは、審議を終了できる条件を判定できない。
実装詳細側に条件が存在しても、SPEC と配布物の契約が一致しない。

## 課題

本質的争点の解消、妥当な批判の反映、撤回済み批判の排除、部分合意範囲、ユーザー判断事項、再検証、新規争点、議論継続自体の目的化という 8 条件を SPEC に反映する必要がある。

## 既存要件、仕様との関連

- `docs/specs/skills/agentdev-deep-review.md`
- `docs/requirements/REQ-003.md` の REQ-003-034
- RU-20260726-01 AG-013
- PR #1832、Issue #1830、Epic #1828

## 対応方向

SPEC に「完了条件」セクションを追加し、8 条件と形式的判定を否定する契約を記載する。
自律審議継続の不足と同じ spec-update で処理できる。

## 発生源

PR #1832 の Findings / Capture候補 F-2。
