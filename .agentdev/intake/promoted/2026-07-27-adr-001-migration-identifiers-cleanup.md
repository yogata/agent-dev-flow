# ADR-001 の移行時識別子 cleanup

## 観測内容

`docs/adr/ADR-001.md` には移行時識別子が 3 箇所残る。
L101 の `WS-9` と L102 の `案B` は、決定内容を変えずに削除できる非意味ラベルである。
L114 の `10シナリオ` は、SPEC が定義を所有し Release Report が実行結果を所有する一方、ADR 本文では規範表現である可能性がある。

## 影響

accepted ADR に移行時の作業識別子が残り、恒久的な決定と移行過程の情報が混在する。

## 課題

L114 の削除が意味変更か非意味修正かを、accepted ADR 更新規則に照らして判定する必要がある。

## 対応方向
