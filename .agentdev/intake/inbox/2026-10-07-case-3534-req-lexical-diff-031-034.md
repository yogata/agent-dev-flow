# REQ-031-027 と REQ-034-043 の実行時重複検出語彙差を統合するか判断する

## 内容

実行時の Wave 内重複検出の対象語彙が REQ 間で分かれている。REQ-031-027 は「変更対象ファイル重複」、REQ-034-043 は「主な変更対象（子 Issue が実行単位として所有する宣言）の重複」。実装側（case-ready Design、配布物の契約記述）は Wave 2-2 で REQ-034-043 語彙へ統一済み。

## 影響

同一概念が REQ 間で異なる語彙のまま残るため、以後の同種の語彙整合変更が REQ 間差を生み続ける。REQ 変更を伴うため対象 Case（Issue 3534）では解消不可だった。

## 提案

REQ-031-027 側の語彙を REQ-034-043 語彙へ統一する REQ 変更の要否を判断する（語彙統合、または語彙差の意味を明記して維持）。

## 根拠

PR #3540「Findings / Capture候補」の intake。Wave 2-2（Issue 3534、RA-002 ライフサイクル責務）の実行で検出され、REQ 変更を伴うため対象範囲外として記録された。
