# 経路識別子廃止の横断検索判定基準（検出対象と一般用語の区別）の明文化候補

## 観測

PR #2426（Issue #2425、経路ラベル廃止）の横断検索で、検出対象（`経路[A-H]` 字ラベル、`7経路` 等 A〜H 識別子体系由来の数量表現）と非対象（`blocked 経路`、`--auto 経路`、`review 経路での ...`、`docs/ 参照3経路` 等の一般用語としての「経路」）の区別を実行時の判断で行った。この区別基準は文書化されておらず、次回の同種横断検索で判定がぶれる可能性がある（PR #2426 本文「Design確定候補」2件目）。

## 今回扱わない理由

判定基準の明文化（Design への確定）は本 Case の完了条件には含まれていない。一般用語の残置判断（delegation-contracts Design の節名「review 経路での …」等）は本 PR で対象外判定を記録済みであり、基準自体の正文化は別案件として後続へ委ねる。

## 影響

なし（今回の判定は PR #2426 Findings の事実報告として記録済み）。未明文化の間は同種の横断検索で検出対象の過不足が生じ得る。

## レビューで決めること

- 区別基準の正規所有先（adversarial-review Design、検証範囲カタログ、または doc-writing の検索手順）
- 数量表現（`7経路` 等）を識別子体系由来と判定する条件の言語化

## 根拠

- PR #2426 本文「Design確定候補」2件目、同「Findings / Capture候補」事実報告（`7経路` の `7呼出元` 更新、一般用語の残置判断）
- Issue #2425 完了条件1・7
