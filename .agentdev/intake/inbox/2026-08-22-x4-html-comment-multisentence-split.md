# X-4 機械判定が HTML コメント内複数文を分割対象とする扱い

## 観測

DEC-009:9 の HTML コメント内複数文が X-4（一文一行）機械判定の対象となり分割された。正規実装 `scripts/apply-mechanical-replacement.ps1` の Apply-X4Split は HTML コメント（`<!-- -->`）を判定除外に含まず、PR #2398 の Node.js 準拠検出器も同じ挙動に従った。結果は DEC-009 では複数行コメントとして構造を保持しており、文意破壊はない。

## 今回扱わない理由

コメント行を判定除外とするかは規則確定側（`mechanical-replacement-rules.md` §4 の一文一行機械判定）の判断事項であり、適用実行側の本 case では正規実装準拠を維持した。

## 影響

判定除外に含めない現行では、docs 中の HTML コメント（テンプレート注記等）に複数文を書くたびに機械是正対象となる。コメント内の文構造は可読性に寄与しない場合もあり、分割が常に改善とは限らない。

## レビューで決めること

- HTML コメント行を X-4 判定除外に追加するか（正規実装・準拠検出器・規則文書の3点更新を伴う）
- 現行維持の場合、規則文書へ「コメント内複数文は分割対象」と明記するか
