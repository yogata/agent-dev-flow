# OpenCode v1.18.23 実機検証（TS-002〜006、TS-008、TS-009）の未実施分

## 観測

Issue 2444（REQ-053、PR 2445）の完了条件に含まれる実機検証 TS-002〜TS-006、TS-008、TS-009 が、委譲環境では OpenCode v1.18.23 実機セッションを起動できないため未実施のまま終了した。対象は非発動・次ターン切替・sessionID 不変・状態維持・復帰・一行通知・失敗報告・重複要求拒否の実動作観察（REQ-053-002〜010、REQ-053-015 の実機確認面、REQ-053-016）。

対象 18 行（REQ-053-001〜017、REQ-052-011）は検証対応要否カタログの全行 catalog-registered（任意行）であり、QG-4 完了阻止条件には該当しないため、case-close 契約「完了条件に含まれる未対応事項は intake 記録として明示し、完了扱いには含めない」を適用して本 item で回収した。機械的検証（unit テスト 33 pass、import 解析、traceability check 7 pass / 0 fail）は pass しており、虚偽の合格記録は存在しない。

## 今回扱わない理由

実機検証は当該 Case の委譲環境では実施不能（OpenCode 実行セッションの起動が必要）。Design（model-escalation-runtime.md、accepted 昇格済み）の検証節も実機検証を観察契約として想定しており、OpenCode v1.18.23 実行環境での手動検証または後続 Case での実施が必要。

## 影響

OpenCode v1.18.23 上での実動作観察（昇格・継続・復帰の一連の状態遷移、REQ-053-016）が未確認のまま運用に供給されている。chat.message 書換の挙動は OpenCode バージョン間で差異があり得るため（Design 既知リスク）、実機未確認のまま OpenCode を更新すると互換性検証なしで動作することになる。
