# SPEC確定候補: 決定値を伴う PR の rebase 時における再計測・文書整合の要否明記

## 観測

AG SPEC「標準候補数上限の決定手順」節は、決定後の rebase を契機とする再計測・文書整合を手順に含まない。PR 2262 では rebase（a08384a2 → 175a2047）により代表ケース数値が変化したため再計測し、AG SPEC と audit Report を整合した（差分文書 §7）。決定値を伴う PR の rebase 時における再計測・文書整合の要否を手順へ明記する候補として記録する。

## 今回扱わない理由

PR 2262（Issue 2204）は標準上限値 12 の決定と手順1〜4の実行結果の明文化がスコープ。決定手順への rebase 時再計測要件の追加は SPEC 改訂であり、case-close の SPEC 確定フローでは昇格対象（draft → accepted）とはならない見送り（パターン c）として記録し後続へ委ねる。

## 影響

決定値を伴う PR が rebase された場合の再計測・文書整合が運用の判断に残る。本 PR では実施済み（増幅実測範囲 42〜75 件を rebase 後実測へ整合、audit Report 節7へ再計測記録を追記）だが、手順上の必須要件ではない。

## レビューで決めること

- 決定手順へ rebase 時の再計測・文書整合を必須手順（手順5相当）として追加するか、判断基準の提示にとどめるか
- 追加する場合、AG SPEC と audit Report の双方の整合を要件に含めるか
